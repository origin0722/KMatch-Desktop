01

项目侦察

目录、语言、构建文件、依赖、配置、测试和入口。预览范围，忽略密钥、产物和越界链接。

02

结构提取

语言适配器提取模块、符号、导入、调用、实现、构建依赖与解析诊断。

03

框架理解

框架适配器按规则识别角色、路由、依赖注入、ORM、配置和测试关系。

04

证据审核

每条框架边核验文件、行号、配置、依赖或测试证据；低置信候选不进入主链。

05

语义图谱

架构、框架流程、代码细节、配置依赖和质量证据五种可切换视图。

Spring Boot 第一条完整纵切

POST /api/users → UserController → UserService → UserRepository → User Entity → users 表

pom.xml → Spring/JPA 依赖　|　application.yml → 数据源/Profiles　|　UserServiceTest → 测试证据

多语言的分层支持

  • Python：迁移现有 AST/Jedi/Pytest 能力至统一适配器。
  • Java：Spring Boot 完整框架 profile。
  • TypeScript：NestJS 作为第二条框架纵切。
  • JavaScript、Rust、C：先提供结构图谱，再按已验证 framework profile 提供语义层。
