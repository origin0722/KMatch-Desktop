# 真机核验清单 v1.3.4（安装包装机验证）

> 目的：v1.3.4 安装包在真实 Windows 机器上的发布前核验（重点覆盖 v1.3.3 新表面 + v1.3.4 热修）。
> 环境：Windows 10/11 x64 干净机或已卸载旧版；联网；一个 DeepSeek 等 OpenAI 兼容 Key。
> 基础功能全量走查见 [测试用例表_v1.3.4](../质量与验收/测试用例表_v1.3.4.md) M 系列。

## A · 安装与启动（约 2 分钟）

- [ ] A1 双击 `KMatch·知链-1.3.4-x64.exe` → 向导完成 → 桌面/开始菜单出现图标
- [ ] A2 首次启动 ≤10 秒状态栏后端点变绿（sidecar 自启，免 Docker/Python）
- [ ] A3 设置 → AI 助手粘贴 Key → 测试连接成功（粘贴带换行自动 trim）

## B · v1.3.4 热修回归（核心，必测）

- [ ] B1 学习会话选方向 → 出题 → **提交答题不再报 "An object could not be cloned."**，
      且等待期显示分步进度（判分→画像→路径组装）
- [ ] B2 提交完成后正确率/策略正常展示；点「获取针对性反馈」同样正常（同一条传输链路）
- [ ] B3 （可选）反馈生成中点「停止等待」→ 非错误提示，可重新获取

## C · v1.3.3 等待体验（约 3 分钟）

- [ ] C1 进数据看板：报告补跑进度逐段可见（路径→生成 N/M→审核→裁判）；二次进入秒开（缓存）
- [ ] C2 补跑中「停止等待」→ 退出再进 → 报告**完整**重跑（无半成品缓存污染）

## D · v1.3.3 图谱（约 4 分钟）

- [ ] D1 知识图谱：搜索关键词高亮；**不配 Embedding 时出现降级提示条且名称匹配可用**（不再无反应）
- [ ] D2 路径查找：选起终点 → 「在图中高亮该路径」→ 图中路径高亮并聚焦
- [ ] D3 打开 Python 项目（可用 `data/example_projects/simple_crawler`）：自动解析成图谱；
      大项目（>150 实体）默认模块分组视图
- [ ] D4 项目图谱：边类型筛选（调用=蓝/继承=琥珀虚线）过滤正确；实体点击→跳源码行
- [ ] D5 编辑并保存任一已解析 `.py` → 出现「图谱已过期」横幅且跳转禁用 → 重新解析后恢复

## E · v1.3.3 去 AI 味（约 2 分钟）

- [ ] E1 AI 助手提问：回答直接切入（无"好的/希望有帮助"式客套），代码块高亮可复制
- [ ] E2 学习资源页讲义：无 `[ref: PY-xxx]` / `[已心算验证]` 标记、无 emoji 标题、
      无"首先/总之"模板腔；测试题可本地作答判分（格式冻结未破坏）

## F · 收尾

- [ ] F1 关闭应用重开：配置/对话/图谱历史恢复；无 sidecar 残留进程（任务管理器查 KMatchBackend.exe）
- [ ] F2 卸载（可选）：控制面板卸载干净，`%LOCALAPPDATA%\Programs` 残留检查

> 全部通过 → 可对外分发。任何 B 组失败 = 阻塞（热修未生效，检查安装版本号）；C/D/E 失败按
> [部署说明排障表](../部署与发布/系统部署说明_v1.3.4.md#七故障排查) 处置并反馈。
