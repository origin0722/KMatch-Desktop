## 1. 软件定位（同 v1.3.0）

**KMatch·知链**：知识图谱驱动的多智能体协同个性化 Python 学习平台（Electron + Monaco 桌面 IDE）。
- **场景一 · 无项目技能训练**：学情测评 → 个性化路径 → 分层资源 → 动态反馈闭环；
- **场景二 · 有项目二次开发**：项目自动解析为代码图谱，审查/测试双 Agent 协同质量反馈。
端用户免 Docker、免命令行、免改 `.env`。

### v1.3.1 → v1.3.4 更新摘要

**v1.3.1（补丁）**：动态建域出题线程 API 配置传播修复（JAVAEE 等未收录领域安装包必现 401 的根因）。

**v1.3.2（可信度收口）**：项目图谱质量检查入口修复+诚实命名；运行历史展示投影不泄漏 request；
图谱历史单项移除；资源阶段延后启动如实表达；预览版用户反馈 7 项收口；测试环境隔离。

**v1.3.3（体验跃升五线）**：

1. **等待体验**：
   - 判分 / 反馈再生 / 报告补跑三条交互主链 **SSE 流式化**——等待期显示真实进度
     （如「正在生成学习内容 3/15：循环·讲义」），取代"转圈+猜测时长"；
   - **停止等待**：等烦了可中止（后台结果照常落缓存，重试秒回；报告取消不写半成品缓存）；
   - **真实提速**：独立裁判并行化（原逐条串行最多 10 次 LLM 是报告补跑大头）；审核打回
     **节点级再生缓存**（只重生成被点名节点，15 次 → 3-6 次调用）；判分可选快模型分流
     （设置页开关，默认关）；生成/审核/裁判全链耗时打点。
2. **图谱**：
   - **修复过期检测失效**（P0）：源文件改动后图谱此前从不提示过期，用户可能按旧行号跳错代码；
   - 解析提速四点（并行读文件 / 免重复 AST / Jedi 推断缓存+上限 / 响应瘦身）；前置依赖
     批量 API（打开图谱 20 次请求 → 1 次）；
   - 交互增强：高亮不再整图重排、搜索防抖、**边类型过滤与三色图例**（包含灰/调用蓝/继承琥珀虚线）、
     大项目默认模块聚合、语义搜索失败降级名称匹配+提示（不再静默）、路径查找结果一键上图高亮、
     动态领域分类补色板可筛选。
3. **去 AI 味**：
   - 生成内容**文风契约**入共享协约（禁"首先/总之"模板腔、列表 ≤6 条、禁 emoji 排版、
     篇幅即诚意；测试题格式冻结豁免保障本地判分）；
   - **机器标记出正文**：`[ref: PY-xxx]`、`[已心算验证]` 不再泄漏进讲义/测试题（提示词禁止 +
     渲染层兜底剥离）；审核意见必须指名位置+具体改法；
   - AI 助手**回答格式规范**：禁开场白/客套收尾/空心列表，散文优先；注入资料防模仿排版；
     流式渲染防跳变（未闭合代码围栏补齐）+ 代码高亮防抖；
   - 界面文案与 emoji 图标清理约 25 处（欢迎语/空态/建议句式差异化）。
4. **终审加固**（发布前双路代码审查 + 深度安全扫描）：修复 9 项审查发现（含边类型字段归一、
   取消不写缓存、IPC 降级恢复等），自有源码安全扫描无高危。

**v1.3.4（热修）**：修复桌面端「提交答题 / 获取针对性反馈」报
`An object could not be cloned.`——流式请求载荷携带 Vue 响应式代理对象无法通过 Electron IPC
结构化克隆。已在传输层单点转纯对象并新增 3 条 IPC 可克隆回归测试。**v1.3.3 安装包受此影响，
请使用 v1.3.4。**

## 3. 功能说明（增量；基础模块见 v1.3.0 文档）

### 3.1 学习会话（v1.3.3 变化）
- 提交答题 → 分步进度（判分 → 画像 → 路径组装）；获取反馈 → 检索/逐段生成进度（1/N）；
- 等待期可**停止等待**（非错误态，可重试；后台结果入缓存重试更快）；
- 等待文案 = 真实进度 + 已等待秒数（不再显示硬编码"最长约 N 分钟"猜测）。

### 3.2 数据看板 / 报告（v1.3.3 变化）
- 进报告页触发补跑：逐阶段（路径→生成 N/M→审核→裁判）进度可见；二次进入命中缓存秒开；
  补跑中途停止等待不会污染缓存（重进完整重跑）。

### 3.3 知识图谱（v1.3.3 变化）
- 搜索：语义检索不可用（未配 Embedding）时自动降级名称匹配并提示条说明；
- 路径查找（BFS）：结果 chip 颜色 = 节点难度色，「在图中高亮该路径」一键定位；
- 筛选新增「动态领域」分类（动态建域的 70 节点此前灰色不可筛）；
- 高亮/筛选增量更新（保留布局与拖拽位置，不再闪一下重排）。

### 3.4 项目图谱（场景二，v1.3.3 变化）
- 打开项目解析提速（大项目秒级）；实体搜索防抖不卡顿；
- **边类型过滤**（包含/调用/继承）+ 三色样式图例——调用关系不再被层级边淹没；
- **>150 实体的大项目默认模块聚合视图**（可切回分层）；
- **过期检测**：改动已解析的 `.py` 文件 → 「图谱已过期」横幅 + 禁用实体跳转（防按旧行号
  跳错代码）；重新解析后恢复。

### 3.5 AI 助手（v1.3.3 变化）
- 回答格式规范（见更新摘要 3）；渲染层剥离残留机器标记；流式长代码块不再排版跳变/卡顿。

### 3.6 设置页（v1.3.3 变化）
- 学习引擎段新增「判分也使用快模型（实验）」开关：默认关（判分质量优先），开启后提交答题
  判分换用反馈快模型，慢端点下明显减少等待。

## 4. 安装与运行（同 v1.3.0 流程）

下载 `KMatch·知链-1.3.4-x64.exe` → 双击安装 → 启动（sidecar 自启）→ 设置页填 AI 助手 Key。
系统要求 Windows 10/11 x64，安装包约 130 MB，需联网。详细部署（开发模式/Neo4j 可选/环境变量表/
排障）见 [系统部署说明_v1.3.4](../部署与发布/系统部署说明_v1.3.4.md)。

## 6. 已知边界（诚实声明）

- v1.3.0 文档所列边界仍适用（无交互终端、Git 需自装、Subprocess 沙箱限制、utcnow 告警）；
- **实体↔知识点关联展示**：后端仅有写入 API 无查询且无数据源，暂无展示价值，待有真实关联数据后立项；
- **知识图谱节点整体配色重编码**（分类=色/难度=徽标）需视觉验收支持，v1.3.3 仅完成路径 chip
  对齐与动态领域补色；
- SSE 取消感知为尽力而为（最迟一个心跳周期 ≤15s；运行中的单次 LLM 调用自然收尾）；
- 演示视频/PPT 按提交材料清单另行制作。
