## 一、演示视频脚本（10 分钟）

> 录制工具：OBS / 系统录屏；分辨率 1920×1080；配音可后期。桌面 app 跑在 1920×1080 全屏，字体放大至 14-16px 确保可读。

### 场景 0：开场（0:00-0:40）

**画面**：标题卡「KMatch·知链 - 知识图谱驱动的多智能体协同个性化学习平台」+ 赛题编号 XH-202630

**旁白**：当前大模型在垂直教育面临「幻觉」「个性化与专业性难调和」「千人一面」三大困境。KMatch·知链以四层知识图谱为共享事实底座、6 个 Agent 协同决策为核心引擎，攻克专业内容高保真生成。下面演示完整闭环。

### 场景 1：差异化画像输入（0:40-2:30）

**画面**：打开 KMatch 桌面 IDE -> 学习视图 -> 学习会话第 1 阶段「目标」。依次切换 3 组画像（零基础应届生 / 入门转码者 / 进阶工程师），展示不同的 `target_direction` 与已有基础输入。

**旁白**：系统面向 Python 学习，覆盖「无项目技能训练」与「有项目二次开发」两类场景。我们准备了 3 组差异化学习者画像--零基础、入门、进阶--分别锚定不同理论底盘与技能盲区。以零基础画像为例进入测评。

**画面**：第 2 阶段「答题」- 学情检测 Agent 题库驱动出题（理论 + 实操），用户作答 -> 提交 -> 生成三维画像（theory_level / practice_level / weak_topics）。

**旁白**：学情检测 Agent 基于知识图谱题库动态出题，作答后产出结构化画像，精准定位盲区节点。这是后续所有 Agent 的输入锚点。

### 场景 2：多智能体协同调度可视化（2:30-5:00）

**画面**：第 3 阶段「协同」- LearningSession 展示主控调度 Agent 编排 6 子 Agent 的流转：图谱管控组装路径 -> 内容生成 3 资源 -> 内容审核逐条校验。AssistantPanel 同步展示工具调用循环（read_file / generate_project_graph 等）与 Agent 实时状态。

**旁白**：主控调度 Agent 编排全流程：图谱管控 Agent 据画像从 92 个 Python 元知识节点抽取并拓扑排序，组装渐进式学习路径；内容生成 Agent 并发生成分层讲义、阶梯实操、分阶测试题三种资源；内容审核 Agent 对照图谱事实逐条校验--这是我们的核心创新「辩论与交叉验证」抗幻觉机制。

**画面**：放大审核环节 - 展示一次「生成->审核->打回->修正」博弈循环（reviewer 命中幻觉 issue -> 打回 -> generator 修正 -> 复审通过），每段内容标注 `source_nodes` 溯源到图谱节点 ID。

**旁白**：审核 Agent 发现不一致即打回并附溯源说明，多轮博弈确保知识高保真。每段内容都标注引用的图谱节点 ID，实现可追溯的约束生成。

### 场景 3：个性化资源生成（5:00-7:00）

**画面**：第 4 阶段「图谱」+ 资源交付区 - 展示该画像生成的 3 种资源（讲义 / 实操指南 / 分阶测试题），排版清晰；点击资源段高亮其 `source_nodes` 对应的图谱节点。

**旁白**：通过审核的资源交付学习者。分层讲义讲理论、阶梯实操练动手、分阶测试固巩固，三种形态均按画像难度自适应，且每段可溯源到图谱事实节点。

**画面**：演示「动态迭代」- 用户答错某测试题（正确率<50%）-> 主控调度触发 remediate 策略 -> 生成降维解释；答对（≥80%）-> advance 进阶挑战。

**旁白**：基于答题正确率，主控调度动态决策：低正确率降维重讲，高正确率进阶挑战，实现真正的个性化迭代。

### 场景 4：可视化报告（7:00-8:30）

**画面**：Dashboard - 三联可视化：知识盲区热力图、资源难度匹配曲线、学习路径规划图。数据来自真实 `learning_report`（非伪造）。

**旁白**：系统生成可视化个人学情与资源匹配度报告：盲区定位、难度匹配曲线、学习路径规划图，帮助培训管理者与学习者直观决策。

### 场景 5：场景二·项目二次开发（8:30-9:30）

**画面**：切换到 code 视图 - 打开一个示例 Python 项目 -> 触发 `generate_project_graph` -> AST 解析生成项目代码图谱（函数/类/调用关系）-> `code_review` 四维度审查 -> `code_test` LLM 生成测试 + 沙箱 pytest 执行 + 反向标注风险节点。Monaco 符号联动（chat 跳转源码行）。

**旁白**：第二类场景，已有项目二次开发。代码解析 Agent 静态分析生成项目图谱，代码审查 Agent 四维度审，代码测试 Agent 生成单测并在沙箱执行，反向标注图谱风险节点。

### 场景 6：设置与收尾（9:30-10:00）

**画面**：设置页 - AI 助手段（8 厂商 + 思考模式 + 工具权限 + 记忆）、Agent 独立 key 段（学情引擎用独立 key + 测试连接）、供应商管理（自定义厂商 CRUD + 视觉探测）、网络代理。

**旁白**：桌面 IDE 形态支持多厂商 LLM、Agent 学习引擎独立 key、自定义供应商与网络代理，一键打包为 Windows 安装包分发。KMatch·知链，让大模型从「通用聊天工具」转变为「懂专业、精技能、能落地」的新型教育基础设施。

**画面**：结束卡 - 项目名 + 赛题编号 + 仓库地址

## 二、方案文档大纲（D01 作品设计实现方案）

> 目标 20-30 页，按以下章节展开。每章标注对应赛题要求与代码位置。

1. **项目概述**
   - 1.1 赛题背景与痛点（幻觉 / 个性化与专业性矛盾 / 千人一面）
   - 1.2 项目目标与定位（Python 学习两类场景）
   - 1.3 核心创新点（图谱共享底座 / 多 Agent 辩论抗幻觉 / 脚手架引导 / 核心+领域插件）

2. **系统架构**
   - 2.1 三层架构（前端 IDE / 后端 LangGraph / 数据层 Neo4j）
   - 2.2 四层知识图谱（领域元知识 -> 项目框架 -> 代码实体 -> 演化扩展）
   - 2.3 进程拓扑（Renderer / Main / Backend / Neo4j）
   - 2.4 技术栈选型与版本

3. **多智能体协同机制**（赛题(2)(4)①）
   - 3.1 6 Agent 职责分工（主控调度 / 学情检测 / 图谱管控 / 内容生成 / 内容审核 / 代码审查 / 代码测试）
   - 3.2 「分析-生成-校验-决策」协同闭环（LangGraph StateGraph 编排）
   - 3.3 辩论与交叉验证抗幻觉（生成->审核->打回博弈 + 0.85 阈值 + prompt 禁图谱外事实）
   - 3.4 知识溯源约束生成（source_nodes 标注）

4. **知识图谱引擎**（赛题(2) 知识库整合）
   - 4.1 四层图谱设计
   - 4.2 Neo4j 5.x 原生向量索引（cosine 1536 维）
   - 4.3 图遍历 + 语义向量混合检索
   - 4.4 学习路径组装（依赖拓扑 + 难度排序 + 弱项补丁）

5. **个性化资源生成**（赛题(2) 3 种形态）
   - 5.1 分层讲义 / 阶梯实操指南 / 分阶测试题
   - 5.2 画像驱动的难度自适应
   - 5.3 脚手架式 5 级引导（场景二）

6. **动态反馈与启发式导学**（赛题(3)②(4)②）
   - 6.1 答题正确率 -> advance/remediate/scaffold 三策略
   - 6.2 tutorMode Socratic 动态追问
   - 6.3 三阶段交互测评（idle/answering/feedback）

7. **可视化报告**（赛题(3)①）
   - 7.1 知识盲区热力图 / 资源难度匹配曲线 / 学习路径规划图
   - 7.2 report_builder 数据契约（demo + interactive 双模式）

8. **质量检测体系**（赛题评分「实用价值 30 分」）
   - 8.1 三指标定义（幻觉率 / 适配率 / 覆盖率）与达标线
   - 8.2 独立判定方法论（见 `docs/质量与验收/M5质量检测方法论升级.md`）
   - 8.3 实测结果与证据链

9. **两类场景全流程**
   - 9.1 场景一：无项目技能训练（学情->图谱->生成->审核->交付->迭代）
   - 9.2 场景二：有项目二次开发（解析->图谱->审查->测试->沉淀）

10. **桌面 IDE 形态**
    - 10.1 Electron + Monaco 架构（sidecar 后端自启）
    - 10.2 AI 助手（SSE 流式 + 工具调用 + write_file 审批门 + 消息分支）
    - 10.3 多厂商 LLM + Agent 独立 key + 自定义供应商 + 网络代理
    - 10.4 代码测试沙箱（subprocess / docker 双模式）

11. **部署与测试**
    - 11.1 Docker 一键部署 + NSIS Windows 安装包
    - 11.2 单元测试（459 后端 + 223 前端）
    - 11.3 数据合规与隐私（合成画像 + 沙箱 env 白名单）

12. **赛题对标自查**（逐条对照赛题五、答题要求与六、评选标准）

13. **创新点总结与未来工作**（领域泛化 / Spec C 联网搜索 / 多 Agent 协同可视化深化）
