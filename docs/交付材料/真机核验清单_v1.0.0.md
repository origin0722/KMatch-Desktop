## 1. 目的与范围

- 安装包：`KMatch·知链-1.0.13-x64.exe`。

## 7. 已知边界（诚实告知，非 Docker 引入）

| 边界 | 说明 | 与 Docker 关系 |
|---|---|---|
| **代码测试沙箱** | 安装包 v1.0.2 起**已随包捆绑便携 Python 运行时（pytest+pytest-cov）→ 场景二「代码测试」在端用户机器可用**（子进程执行，AST 预检 + env 白名单；禁网/限内存等强隔离仍需 Docker 沙箱）。运行时缺失时回退报错提示 | 无 Docker 已可用（弱隔离）；Docker 用于强隔离 |
| **语义/混合检索** | 需要 **Embedding API Key**（云端编码 query）；无 key 时自动降级纯图模式（StatusBar 琥珀「纯图模式」），路径/图谱/答题不受影响。首跑自动回填节点向量发生于**可写用户目录**，不占安装目录 | 云端服务，非本机依赖 |
| **LLM 依赖** | 测评判分/AI 助手/内容生成均需用户自己的 LLM API Key | 云端服务，非本机依赖 |
| 语义离线种子 | 若发行前跑了 `scripts/export_embeddings.py`，端用户首跑即免向量回填（本版未附带种子） | 可选增强 |

**结论口径**：不开 Docker 可完成全部核心功能（含场景二代码测试——v1.0.2 起随包便携 Python 运行时）；唯一的隔离强度差异是代码测试沙箱（子进程弱隔离 vs Docker 强隔离），不影响功能闭环。
