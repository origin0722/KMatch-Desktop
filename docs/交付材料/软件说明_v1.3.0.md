## 1. 软件定位

**KMatch·知链** 是一款「知识图谱驱动的多智能体协同个性化学习平台」，面向 **Python 编程学习**，
覆盖两类核心场景：

1. **场景一 · 无项目技能训练**：零基础/进阶学习者通过「学情测评 → 个性化路径 → 分层资源 →
   动态反馈」完整闭环学习 Python；
2. **场景二 · 有项目二次开发**：学习者携带真实代码项目，平台自动解析为**项目代码图谱**，
   由代码审查/代码测试双 Agent 经 **LangGraph 流程编排**协同给出架构解读、技术栈检测与质量反馈。

产品以 **Electron + Monaco 桌面 IDE** 形态交付：内置代码编辑器、文件树、AI 助手、
知识图谱、Git 版本管理、运行历史与数据看板，**端用户免 Docker、免命令行配置、免改 `.env`**。

### v1.3.0 更新摘要（赛前审查加固）

1. **截断治理**：SSE 流新增 `finish_reason='length'` 探测——模型因输出上限停笔时，
   回答末尾显式提示「已达到输出上限」，不再让用户把戛然而止当答完；DeepSeek-V4
   默认思考档不再强制开启（仅 high/max 显式启用），思考不再默认吃掉正文预算；
   Agent 生成统一 16384 token 输出上限（长讲义/实操不再被厂商默认 8K 拦腰截断）；
   代码块限高 200→480px 且可展开；流式尾部残留帧防御性冲刷；工具轮数默认 6→8。
2. **API 自愈**：学习引擎设置页新增「获取模型」——拉取厂商真实模型列表并自动校正
   不存在的模型（修复「Key 有效却反复 400 Model Not Exist」）；API Key 保存后自动
   ping 校验，无效 Key 当场提示（不再等到出题才 401）；后端新增「模型不存在」友好
   报错（区分 401 与 400，各自给修复指引）。
3. **画像细致化**：每周可学时长 / 学习节奏由写死值改为真实采集（测评入口可选填写），
   画像 demographics 放宽至年龄段/编程经验/Python 经验；**设置页新增「学习画像」段**：
   查看理论/实操等级、学习风格徽标、逐知识点掌握度、学习历史，可编辑背景信息、
   导出画像 JSON、重置档案（后端新增 GET/PUT/DELETE `/api/diagnostics/profile/{key}`）。
4. **数据合规落地**：新增交互日志脱敏组件 `backend/app/utils/redaction.py`
   （`PRIVACY_REDACT_INTERACTION_LOGS` 开关 + 敏感字段脱敏规则表，见合规说明）。
5. **提交物策展**：新增 [测试数据_输入输出示例.md](测试数据_输入输出示例.md)——
   2 组差异化学习者「画像 → 多智能体中间态 → 个性化资源」完整输入输出走读。

## 3. 功能说明（按模块）

### 3.1 桌面 IDE 工作台
- **左侧导航栏**：代码 / 学习会话 / AI 助手 / 知识图谱 / 项目图谱 / Git 仓库 / 学习资源 /
  数据看板 / 运行历史 / 设置；支持折叠为 48px 图标轨（持久化）。
- **资源管理器**：打开/最近打开（可单条删除）、懒加载目录树（大项目不卡顿）、
  文件内联预览（图片/PDF/Markdown/HTML 沙箱）。
- **Monaco 编辑器**：多标签、未保存脏标记、外部文件变动失效/冲突提示、代码符号概览。
- **状态栏**：后端健康、本地存储/纯图模式指示灯、文件状态。

### 3.2 AI 助手（对话）
- OpenAI 兼容多厂商（DeepSeek/自定义厂商），SSE 流式输出；
- **工具调用**：13 个工具（读文件/写文件审批门/执行代码/图谱查询/联网搜索/学习路径等），
  只读工具结果**自动回喂**对话，多轮工具循环上限默认 8 轮（设置页 1-12 可调）；
- **导学模式**（苏格拉底式）：以引导追问替代直接给答案；
- **会话分支/续写/重新生成** + 记忆开关 + **对话持久化**（重启恢复）；
- **流式指标栏**：首 token 延迟 / tok·s⁻¹ / 缓存命中 / 输入·输出 token；
- **v1.2.0 优化**：历史预算裁剪（长对话只送相关上下文）、流式滚动守卫（回看不被抢滚）、
  IPC 看门狗 + 真停止（卡死请求可中断）、输入框可粘贴治理统一；
- **v1.3.0 截断治理**：输出上限截断显式提示（`finish_reason='length'` 探测）、
  DeepSeek-V4 默认档不再强制思考、代码块可展开、流式尾部防御、工具轮数默认 8。

### 3.3 学习引擎（场景一）
- **学情测评**：interactive 三阶段抽题判分，**三维画像** = 理论水平 + VARK 学习风格问卷
  （视觉/听觉/读写/动觉）+ practical_level 实操倾向；**v1.3.0 起每周可学时长 / 学习节奏
  真实采集**（可选填写，缺省 6 小时/跟随推荐）；
- **个性化学习路径**：叠加图谱 BFS 最短路径 + 掌握度加权 + 每周可学时长 → 折算「预计 N 周」；
- **资源生成→审核→交付**：内容生成 Agent → 内容审核 Agent（四维报告：准确性/难度/结构/安全）
  → 打回定向再生（retry_hint 注入）→ 交付报告；interactive 报告补跑接入**有界审核回环**；
- **动态迭代策略**：正确率低 → `remediate` 降维解释；正确率高 → `advance` 进阶挑战；
- **三形态资源**：分层讲义 / 阶梯式实操指南（5 级脚手架渐进揭示）/ 分阶测试题；
  学习资源覆盖 3→5 个薄弱节点，生成失败原因透明化展示；
- **薄弱点联网搜索**：答题薄弱主题一键补充 Tavily 外部资源；
- **画像跨次进化**：稳定 learner 档案 + 加权合并掌握度 + 版本 diff + 30 天遗忘降级。

### 3.4 知识图谱
- **四层图谱**：领域元知识 → 项目框架 → 代码实体 → 演化扩展（6 域 222 节点 + 93 题库
  独立 Question 节点；未收录领域由**动态建域 Agent** 现场构建迷你域）；
- **交互**：节点放大/缩小、BFS 最短学习路径查找、节点详情「重测该点/问 AI」；
- **v1.2.0 图谱体验**：CJK 感知动态节点宽度（中文标签不再截断）+ 力导布局优化 +
  **Excalidraw 确定性导出**（可二次编辑的 .excalidraw 文件）；
- **历史图谱**：知识图谱与项目图谱均可从本地快照回看（无需重新打开项目文件）。

### 3.5 项目图谱（场景二）
- 打开项目自动后台解析为代码实体图谱（重启恢复 + 本地缓存）；
- **Monaco 符号联动**：编辑器选中符号 ↔ 图谱高亮；
- **LLM 架构解读** + 技术栈检测 + 联网补齐学习资源；
- **场景二 LangGraph 流程编排**（`project_workflow` + `/api/project/pipeline`）：
  解析→审查→测试按图编排、状态可观测；
- 代码审查/代码测试双 Agent 协同，沙箱执行（环境变量白名单，密钥不外泄；可选 Docker 真隔离）。

### 3.6 Git 仓库面板
- **克隆远程仓库**：输入 HTTPS/SSH 地址 → 选择目标文件夹 → 自动克隆 → **自动切换项目**
  并触发项目图谱解析；
- **初始化仓库**：把当前文件夹纳入 Git 版本控制；
- **状态面板**：分支徽标 + 更改文件着色列表（未跟踪/新增/修改/删除/重命名/冲突）；
- **提交**：提交说明 + 「暂存全部并提交」（`git add -A` + `git commit`）；
- **拉取 / 推送**、最近 10 条提交、命令输出（成功/失败配色）；
- **实时刷新**：编辑/保存文件后 300ms 去抖自动刷新更改列表；
- **安全**：主进程 `execFile('git', args)` 无 shell 注入；HTTPS 凭据由系统 Git
  凭据管理器/用户 token 处理，**应用不保存任何密钥**。

### 3.7 运行历史与可观测
- 每次学情/学习 run 结构化事件落盘（`run_store`），支持复盘、**按此重跑/重新测评**；
- 流程图 DAG（只读进度）+ Agent 状态可视化；
- 流程工作台（编辑/回滚，导航默认隐藏，供进阶用户）。

### 3.8 数据看板 / 学习资源
- 学情雷达图（三维画像维度）、掌握度分布、趋势图（echarts）；
- 学习资源库（讲义/视频链接/联网收藏），按方向/难度筛选。

### 3.9 设置页（端用户唯一配置入口）
- **AI 助手**：厂商/模型/key + 连通性测试 + 思考模式 + 工具权限 + 记忆；
- **学习引擎**：独立 key（可留空 → **自动回退 AI 助手 key**，页面显示生效来源）+ 测试连接；
  **v1.3.0**：Key 保存后自动 ping 校验、「获取模型」拉取厂商真实模型列表并自动校正；
- **学习画像（v1.3.0 新增）**：画像概览（理论/实操/风格徽标）、逐知识点掌握度、
  学习历史、背景信息编辑、导出 JSON、重置档案；
- **联网搜索**：Tavily key + **一键测试连接**（`/api/search/verify`）；
- **自定义厂商** CRUD + 视觉能力探测 + 网络代理；
- **数据与质量段**：语义检索（Embedding key）/ **异源裁判**（JUDGE_LLM 独立配置）/
  存储状态一览；
- **高级参数卡**：对话 temperature 等运行时参数，`/api/settings` **即时生效**
  （`LOCAL_DIR` 持久化，端用户零 `.env`）；
- **配置导入导出**：一键备份/迁移全部设置；
- **通用**：默认视图、导航折叠、主题皮肤（默认深青珊瑚）、每周可学时长、首次引导重放。

### 3.10 系统能力与安全
- 无边框窗口 + 系统托盘常驻；
- Electron sandbox/CSP 加固；文件写操作联邦（fs-write 守卫）；
- 数据合规：虚构合成画像（无真实个人数据）、本地存储；**v1.3.0 交互日志脱敏组件**
  （敏感字段脱敏规则表 + `PRIVACY_REDACT_INTERACTION_LOGS` 开关），隐私说明见
  [docs/合规与安全/数据合规与隐私保护说明.md](../合规与安全/数据合规与隐私保护说明.md)。

## 4. 安装与运行

1. 从 GitHub Release 下载 `KMatch-Desktop-1.3.0-x64.exe`；
2. 双击安装（可选安装目录），从开始菜单/桌面启动；
3. 首次启动自动拉起后端 sidecar（`KMatchBackend.exe`，免 Docker/免 Neo4j）；
4. 打开 **设置** 页填入 AI 助手 API Key（DeepSeek 等 OpenAI 兼容厂商）→「测试连接」成功即可开始；
   学习引擎/联网搜索/语义检索/异源裁判 key 均可在设置页配置（学习引擎可留空自动回退）。

系统要求：Windows 10/11 x64；安装包约 150 MB；需联网（LLM/Tavily/Embedding 调用）；无需 Docker。

## 6. 已知边界（诚实声明）

- **无真实终端**：Git 面板为命令按钮流（克隆/状态/提交/拉取/推送/历史），非交互 shell；
  冲突合并/分支切换等高级操作暂未提供；
- **Git 需自行安装**：应用不捆绑 Git；未安装时 Git 视图给出官方下载指引；
- **沙箱限制**：Subprocess 沙箱可防密钥外泄但无法真禁网/限内存，需要更强隔离请启用
  Docker 沙箱（可选）；
- **utcnow 弃用告警**：部分时间戳仍用 `datetime.utcnow()`（仅告警，不影响功能），
  计划后续版本迁移到 timezone-aware API；
- **演示视频/PPT**：按赛题提交材料清单另行制作。
