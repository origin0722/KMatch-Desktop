# M5 质量检测方法论升级方案

> 赛题 XH-202630 评分「实用价值 30 分」硬指标：专业知识谬误率（幻觉率）<5%、画像-资源难度适配准确率≥85%、核心知识点覆盖率≥90%。
>
> 本文档指出当前 M5 实测的**可信度风险**，给出**独立判定 + 扩样本 + 证据链**升级方案，使三指标经得起评委追问。

## 一、现状

### 1.1 指标定义与测法（`backend/app/agents/quality_metrics.py`）

| 指标 | 公式 | 数据来源 | 达标线 |
|---|---|---|---|
| 幻觉率 | `1 - avg(factual_accuracy.score, hallucination.score)` | **reviewer agent** 的 LLM 自评维度分 | <5% |
| 适配率 | `difficulty_match.summary.matched / total_resources` | **content_generator** 生成时自评难度 vs 节点难度（\|gap\|≤1） | ≥85% |
| 覆盖率 | `\|weak_topics ∩ learning_path\| / \|weak_topics\|` | 图谱节点集合运算（客观） | ≥90% |

### 1.2 当前实测（`docs/质量与验收/质量检测报告.md`，2026-06-19 由 `scripts/run_quality_test.py` 生成）

- 3 画像 × 9 资源 = 27 样本，单领域（Python）
- 幻觉率 0.0% / 适配率 100.0% / 覆盖率 100.0%
- 三项全达标且完美

## 二、可信度风险

1. **循环验证（最关键）**：幻觉率由 reviewer agent 自评，而 reviewer 与 content_generator 共用同一 LLM（DeepSeek）+ 同源 prompt 体系。generator 生成的内容，reviewer 自评幻觉率→0%，等价于「让作者自己批改自己的作文」，0% 数字对评委缺乏说服力。
2. **适配率近乎必然**：content_generator 生成资源时即按 `profile.difficulty` 自适应难度，`difficulty_match` 又用 generator 自评难度比对→100% 是结构性结果而非质量证据。
3. **样本过小**：3 画像 × 9 资源 = 27，单领域，无第二领域（ML）泛化证据；赛题「实用价值」得分策略明确含「第二领域泛化验证」。
4. **报告陈旧**：2026-06-19 生成后近 1 个月未重跑，期间 Spec A/B 多次改动 LLM 链路。

## 三、升级方案

### 3.1 独立幻觉判定（LLM-as-Judge + 人工证据链）

新增**独立裁判**，与 generator/reviewer 解耦：

- **不同模型**：裁判用与生成不同的模型族（如 Anthropic Claude 或通义千问，通过 `agentLlm` 独立 key 或 `aiSettings` 切换），避免同源偏见。
- **隔离 prompt**：裁判只拿到 ① 生成内容片段 ② 对应图谱事实节点（`source_nodes`），**不拿** generator 的推理过程 / reviewer 的判定。输出结构化判定：
  ```json
  {"verdict": "grounded|hallucinated|unverifiable", "evidence_node_ids": [...], "reason": "..."}
  ```
- **人工抽检证据链**：从批量结果抽样 N 条（stratified by 画像×资源类型），人工逐条对照图谱节点标注，留 evidence 链（资源句 → 图谱节点 ID → 一致/冲突）写入报告附录。

新增函数（`quality_metrics.py`）：
```python
def compute_hallucination_rate_independent(
    resources: list[dict], kg: KnowledgeGraph, judge_llm
) -> dict:
    """独立裁判幻觉率。resources 各句段 -> 裁判判定 -> hallucinated/total。
    与 compute_hallucination_rate 并存，报告中双列对比。"""
```

### 3.2 适配率独立难度评估

新增裁判对资源**实际难度**独立打分（不看 generator 自评），再与画像 level 比对：
```python
def compute_adaptation_rate_independent(resources, profile, judge_llm) -> dict:
    """裁判独立评资源难度 -> 与 profile.theory_level/practice_level 比对 (|gap|<=1)。"""
```

### 3.3 扩样本

- 画像：3 → ≥10（零基础/入门/进阶 × Python；再加跨背景变种）
- 领域：Python 主领域 + ML 第二领域（赛题(1)「至少 1 垂直领域」+ 实用价值「泛化验证」双覆盖）
- 每画像跑多条学习路径（不同 `target_direction`），样本量 ≥10×3×3 = 90 资源
- `data/user_profiles/` 扩到 ≥10 组；ML 节点入 `data/knowledge_base/`（复用 `知识库扩展指南.md` 流程，无需改代码）

### 3.4 覆盖率保持

覆盖率已客观（集合运算），扩样本后自然更有意义，无需改算法。

## 四、落地步骤

1. **裁判 prompt**：新增 `data/prompts/judge_hallucination.txt` + `judge_difficulty.txt`（结构化输出契约）
2. **`quality_metrics.py`**：加 `compute_hallucination_rate_independent` + `compute_adaptation_rate_independent`；`compute_quality_metrics` 增 `independent_*` 并行字段
3. **`scripts/run_quality_test.py`**：扩画像列表 + 接裁判 LLM + 输出双列（self vs independent）+ 证据链附录
4. **`docs/质量与验收/质量检测报告.md`**：重跑刷新（自动生成），附 evidence 链 + 双列对比 + 样本说明
5. **ML 第二领域**：导入 ~30 ML 知识点，跑 ML 画像子集，单列「跨领域泛化」指标

## 五、验收标准（评委可追问的点）

- [ ] 三指标可复现（`run_quality_test.py` 一键重跑，无人工干预）
- [ ] 幻觉率 double-blind：裁判模型 ≠ 生成模型；prompt 不含 generator 推理
- [ ] 证据链：每条 hallucinated 判定可追溯到资源句 + 图谱节点 ID + 冲突说明
- [ ] 样本量 ≥90 资源，跨 2 领域、≥10 画像
- [ ] 报告含 self vs independent 双列，承认 self 评的局限
- [ ] 即使 independent 数字高于 self（如幻觉率 3% vs 0%），仍 <5% 达标——这才是有说服力的达标

## 六、优先级

距 9/5 截止约 7 周。本升级直接加固「实用价值 30 分」硬指标，**应排在 Spec C（联网搜索）之前**。预估工时：裁判 prompt + quality_metrics 改造 1-2 日，扩画像/ML 数据 1-2 日，重跑+报告 0.5 日，人工抽检 0.5 日，共 3-5 日。
