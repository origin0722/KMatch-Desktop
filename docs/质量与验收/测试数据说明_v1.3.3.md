## 三、测试数据生成 / 再生

| 目标 | 命令 |
|:---|:---|
| 离线向量种子再生 (Neo4j→JSON) | `python backend/scripts/export_embeddings.py` (需 EMBEDDING_* 配置) |
| 裁判真模型黄金集 | `python backend/scripts/run_judge_golden.py` (live, 消耗 LLM 调用) |
| 抽题可复现 | `prepare_questions(..., seed=<int>)` — 显式 seed 结果可复现 (1ce4c97) |
| 全量回归 | 见部署说明第三节 (797 + 566) |

## 四、数据边界与合规口径

- 题库/知识节点为自研策展内容, 不含第三方受版权保护文本。
- 用户数据 (API Key/对话/画像) 仅存本机; 后端不回传; 交互日志经脱敏组件出展示 (v1.3.0)。
- 演示评测若需「新领域动态建域」用例 (联网检索), 建议使用 `JUDGE_LLM_*` 独立配置以免消耗主 Key 配额; 动态建域产物不纳入 M5 指标 (契约第 6 节)。
