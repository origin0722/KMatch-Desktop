### (2) 多智能体协同与生成机制 —— ✅ 完全符合

- **9 个职责明确的 Agent**：主控调度（LangGraph StateGraph 编排）/ 学情检测 / 图谱管控（唯一 Neo4j 操作者）/ 内容生成 / 内容审核 / 代码审查 / 代码测试 + 独立裁判（LLM-as-Judge，可异源配置）/ 动态建域；每个 Agent 有独立系统提示词（data/prompts/ 11 文件，契约测试钉住一致性）。
- **"分析-生成-校验-决策"闭环**：场景一 `orchestrator` 编排（学情检测→画像审核→图谱组装→内容生成→内容审核→打回/通过，含重试上限降级）；场景二 `project_workflow`（审查→测试打回→修复裁决）。决策由正确率阈值确定性驱动（≥0.8 advance / ≥0.5 remediate / <0.5 scaffold，`workflow_def` 流程级声明单一真相源）。
- **先验画像+知识库→≥3 形态资源**：三维测评产出画像 v3 → 路径组装 → 每节点生成【分层讲义】【阶梯式实操指南（5 级脚手架渐进揭示）】【分阶测试题（基础 50%+进阶 30%+挑战 20%）】，全部带 `source_nodes` 溯源标记。

### (4) 创新性 —— ✅ 符合（本次补齐 2 处）

- **知识溯源与约束生成**（五层机制，完全有据）：①生成前约束 prompt（只用节点事实、禁图谱外细节）②生成中 `source_nodes` 锚定 + `unverified_claims` 认识状态自声明 ③审核硬规则逐条校验溯源引用 ④裁判 `evidence_node_ids`/`coverage`（full/partial/none）量化 ⑤`compute_anchor_coverage` 锚定覆盖率指标。
- **辩论与交叉验证**：
  - 交叉验证（原有）：独立裁判盲判（不输入生成过程与审核结论，可与主 LLM 异源并诚实标记 same_source）+ 审核硬规则/LLM 双通道。
  - **本次补齐「申诉-复审辩论制」**：打回再生时生成 Agent 结构化举证（`rebuttal: [{issue, response, evidence}]`），审核 Agent 逐条裁定（`rebuttal_verdicts: accepted/rejected + reason`，采纳可有限提分、驳回维持），裁定随审核轮次落盘，前端"申诉-复审"面板可视化。
  - **本次补齐在线闭环**：独立裁判此前仅在离线质检脚本，现接入 `/api/learning/report` 补跑回环（有界 ≤5 条盲判，失败降级不阻塞报告），报告带 `judge_summary`（锚定/幻觉/无法核验 + 异源标记）。
- **动态追问与启发式导学**（原有，符合度高）：导学模式（苏格拉底式 prompt，每轮强制一个追问）+ 学情画像/再生讲义实时注入系统提示 + 图谱工具动态查证（search_knowledge/get_learning_path）+ 图谱节点/专业导读预填多轮导航 + `generate_learning_resources` 自主触发再生成。
