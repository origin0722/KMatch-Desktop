## 二、关键决策

- **仅助手重生成分支, 用户消息编辑不做**: 导学场景重生成价值大 (探索不同引导路径); 用户编辑多修正笔误, 覆盖即可。YAGNI。
- **任意助手可重生成, 后续隐藏非树形**: Apix/ChatGPT 标准行为。重生成第 N 条时, 其后消息隐藏 (不删), 切回原版恢复。线性 versions + trailingAfter, 非树形 (树形 parent/children 过度设计)。
- **trailingAfter 模型 (非 spanEnd)**: 最终 review 发现 spanEnd 单索引断点模型分不清"旧 trailing (该隐藏)"和"regen 后新追加消息 (该显示)", 导致最常见流程"重生末条→追问"静默丢弃用户消息。回退 spec 原始 trailingAfter (每版记录自己可见的 trailing 消息 id 集合), 精确表达归属。_addMessage 追加消息时维护前一个助手 active version 的 trailingAfter。
- **交互舒服不炫**: hover 浮现 (不常驻干扰), 切换淡入淡出 150ms, 单版本不显示箭头, reduced-motion 兜底 (常驻+瞬切), streaming/审批门禁用 regen 避免并发。
- **后端契约不变**: chunks 是纯前端模型, API 历史经 stripToolCalls(contentTextOf) 序列化, 只发当前 version 链。
