# 四流增强：图谱问AI / 项目自动成图谱 / 助手工具升级 / 引导双场景

> 2026-08-15 | 阶段17 | P1-P4 四条独立流, 纯前端改动 (后端 API 已齐)

## 背景

用户提出四项增强需求:
1. 初次进入应用的引导可以更好
2. AI 助手如何协助用户学习领域知识和二次开发需要继续开发
3. 如何将用户上传的项目解读并制作成知识图谱
4. 对于图谱中用户不理解的知识如何去询问 AI 助手

按 P1->P2->P3->P4 顺序执行, 每流独立 commit + 测试。

## P1 图谱节点 -> AI 助手问询通路 (需求④)

**核心**: 图谱/项目图谱详情面板加"问 AI"按钮 -> 预填结构化问题到助手输入框 (不自动发送, 用户可编辑)。

- `stores/chat.js` 新增 `draft` ref + `setDraft(text)`: 跨组件共享预填文本
- `AssistantPanel.vue` 输入框 `inputText` 改绑 `chat.draft` (computed get/set), 双形态共用
- `KnowledgeGraph.vue` 节点详情加"问 AI 助手"按钮: 节点名/难度/掌握度/key_points -> 苏格拉底式预填
- `ProjectGraphView.vue` 实体详情加"让 AI 解释"按钮: 实体名/类型/行范围/调用关系 -> 架构解读预填
- 抽 `utils/askAi.js` 纯函数 `buildNodeQuestion`/`buildEntityQuestion` (组件只收集上下文)
- 19 单测全过 (chat-draft 3 + askAi 9 + format-colors 3 + useGraphData 4)

## P2 项目自动解析成知识图谱 (需求③, 自动解析)

**核心**: 打开项目后后台自动解析 Python 代码 -> 知识图谱落 Neo4j, 重启可恢复。

- 新建 `api/project.js`: `parseProjectFiles`/`getProjectGraph`/`normalizeGraphResponse`/`readProjectPyFiles` (提取自 chat.js)
- `projectGraph store` 新增 `parseCurrentProject`/`restorePersisted`: parsing/parseError 状态机 + localStorage 记 projectId
- `workspace store` 新增 `onProjectOpened` 监听: openProject 成功后通知订阅者 (projectGraph 后台解析, 不阻塞文件树, 尊重 C2 解耦)
- `ProjectGraphView` 空态加"解析当前项目"大按钮 + 解析中 loading + 失败重试; 工具栏加"重新解析"; onMounted 恢复
- `registry` `generate_project_graph` 默认 `write_to_neo4j=true` (模板+广告+执行器同步)
- `chat.js` 复用 `api/project` 共享函数, 删除重复 `_readProjectPyFiles`
- 10 单测全过 (normalize 2 + parseCurrentProject 4 + restorePersisted 4)

## P3 AI 助手学习/二开工具增强 (需求②)

**核心**: 助手能"看到"知识图谱和项目图谱的事实底座, 减少幻觉。

- `registry` 新增 3 只读工具 (全部 ALLOW):
  - `search_knowledge`: 语义检索知识点 (`semanticSearch` -> /api/graph/search)
  - `get_learning_path`: 个性化学习路径 (`assemblePath` -> /api/graph/path, 读画像 known/weak)
  - `query_project_graph`: 查已落库项目图谱 (`getProjectGraph` -> /api/project/graph/glm_5.2_ark_toC, 读 store/localStorage pid)
- `chat.js` 加 3 执行器 + `MAX_TOOL_ROUNDS` 3->6 (多文件探索类任务不再半途断粮)
- `generate_learning_resources` 未完成测评时返回引导文案 (非硬报错)
- 导学/非导学 prompt 补"知识点优先 search_knowledge/get_knowledge_node 查证, 项目架构优先 query_project_graph"
- assistant-settings 测试 9->12 工具行同步; 8 新单测全过

## P4 模态引导升级 (需求①, 仅模态卡片)

**核心**: 引导 Step2 改双场景卡, 按场景落地不同视图。

- `OnboardingOverlay` Step2 改双场景卡: 🎓学新技能(无项目从零学) / 🔧有项目二次开发
- 学新技能场景 goal(basic/crawler/data/web) -> 方向文本写入 `kmatch-onboard-direction`
- `StageGoal` onMounted 读取 `kmatch-onboard-direction` 预填 `form.targetDirection` (tag 自动高亮)
- 完成落地按场景: 学新技能->learning-session, 有项目->code
- 修双写: `finish` 不再写 `kmatch-onboarded` (sidebar store 单点写); 跳过/完成清 step 残留
- `done` 事件携带 `(skipped, scene)` 供落地决策
- 9 单测全过 (含双场景/方向映射/清残留)
