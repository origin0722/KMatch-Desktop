## 已有前端脚手架

项目已搭建好骨架，可直接在此基础上开发：

```
frontend/
├── package.json          ← Vue3 + Element Plus + G6 + ECharts + Axios
├── vite.config.js        ← 代理 /api → localhost:8000
├── index.html
└── src/
    ├── main.js           ← 入口：Element Plus + Router + Pinia
    ├── App.vue           ← 顶栏 + 侧边导航 + 路由出口
    ├── router/index.js   ← 7 个页面路由
    ├── views/            ← 7 个页面骨架（占位，待开发）
    │   ├── Home.vue              首页
    │   ├── Assessment.vue        学情测评
    │   ├── KnowledgeGraph.vue    知识图谱
    │   ├── Learning.vue          学习资源
    │   ├── AgentView.vue         Agent 协同
    │   ├── Dashboard.vue         数据看板
    │   └── ProjectUpload.vue     项目上传
    └── components/
        └── GraphDemo.vue  ← G6 基础渲染 Demo（第1周验证用）
```

