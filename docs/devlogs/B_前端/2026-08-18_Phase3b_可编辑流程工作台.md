## 三、设计与边界

- **事务语义落地**：编辑不生效，显式"提交发布"才校验+原子发布；维护"存草稿"层；每次提交留 revision + 提交说明（`reviewed_by` 字段留给未来接"当前会话 Agent 审查"——dsh-flow 的 AI 审查环节因需运行态 LLM，本版以**可审计元数据 + 确定性校验**体现，接 AI 为文档化扩展点）。
- **内置禁改**：编辑内置流程须改 id 以"衍生副本"发布（同 dsh-flow 不可遮蔽内置）。
- G6 画布为**只读预览**（Phase 3a 组件复用）；拖拽连线编辑为画布级后续细化，本版编辑器以"面板 + 依赖勾选 + 实时预览"承载拓扑编辑，交互逻辑纯化可单测。
