# 2026-08-18 — 体验优化三连：测试题先自测 · 图谱重测入口 · 协同 DAG 定义驱动

**会话目标**：落实用户反馈的三件体验优化（03/04/06）+ 按建议隐藏流程工作台入口。

## 一、③ 分阶测试题：先自测、后对答案

- 根因：`Learning.vue` 测试题 tab 直接渲染**生成原文**（内嵌 `**答案**/**解析**`），答题前答案就暴露。
- 修复：`isTestResource` + `testRevealed` 门控——测试题资源在**提交/显式对照前不渲染原文**，题干与选项走解析出的 quiz；其他资源不受影响。

## 二、④ 知识图谱「重测该点」入口

- 实情：图谱/项目图谱详情面板**已有「问 AI 助手」**（`askAiAboutNode/Entity` → `buildNodeQuestion` 预填 `chat.draft` → 切 chat 视图）。
- 新增：KnowledgeGraph 详情面板加「**重测该点**」+ 提示「概念不熟→问 AI · 想判掌握度→重测该知识点」——以该知识点为目标方向 `startAssessment` 并切学习会话（项目图谱实体为代码实体，重测不适用，保留"让 AI 解释"）。
- 结论：**图谱不会的知识点两条路都给**——判断"会不会"用重测，理解概念用问 AI。

## 三、⑥ Agent 协同 DAG：workflow 定义驱动真实拓扑

- `lastRun.workflow` 快照（Phase 2 落盘）进 `useFlowStatus`：有定义 → 按阶段 id/label/依赖渲染真实拓扑（agents 聚合状态 + 依赖边）；无定义（直播中）→ 回退 AGENT_DEFS 线性链。
- `StageAgent` 传 `lastRun.workflow` + `edges` 给 `FlowDiagram`。
- 效果：复盘态看到的是与流程工作台一致的阶段化拓扑（如 review-profile/review-content 独立成阶段），直播态保持实时线性进度。
