# 2026-08-18 — 全面流畅度优化 A–G（减卡顿）

**会话目标**：按"高价值低风险 → 中等 → 顺手"把可优化点全部落地，提升启动与交互流畅度。

## A. 启动提速：Monaco 进首屏 chunk（启动慢元凶）
- `MainArea.vue`：`MonacoEditor` 由静态 import 改 `defineAsyncComponent` 惰性加载。
- 效果：默认首屏（learning/图谱等）不再下载 Monaco（约数 MB），进入 code 视图才加载。

## B. MonacoEditor 外部改动监视去深
- `watch(externalChanges, handler, { deep:true })` → 去掉 `deep`（响应式 Map mutation 本就会触发）。
- 保存/外部同步时不再深度代理遍历整表。

## C. G6 图谱重绘 rAF 节流（SSE 进行中/快速切换卡顿）
- `FlowDiagram`：状态/拓扑变化 `setData+render` 包 rAF（一帧合并多次）。
- `KnowledgeGraph`：persona/布局切换新增 `scheduleRebuild` rAF 合并（大图谱连点不再反复全量重排）。

## D. 项目图谱解析不冻结 UI
- `projectGraph.parseCurrentProject`：`parsing=true` 后先 `setTimeout(0)` 让出主线程渲染"解析中"；加 `_parseToken` 丢弃过期调用（旧项目结果不覆盖新项目）；`finally` 只在最新 token 清 parsing。

## E+G. 流式事件/日志去重 + 窗口上限
- `assessment.js`：去重从 `.includes`/`.some` 线性扫描改 **Set O(1)**（消除流式累积 O(n²)）；`_MAX_TAIL=500` 数组窗口防长会话膨胀；`_applyResult`/`reset` 同步 seen 集合。
- G（顺手）：同一批高频事件只在首帧打入，配合 C 的图谱 rAF。

## F. ResizablePanel 拖动 rAF + will-change
- `pointermove` 高频 → rAF 合并一帧一写；面板 `will-change: width` 提示合成器独立层。
