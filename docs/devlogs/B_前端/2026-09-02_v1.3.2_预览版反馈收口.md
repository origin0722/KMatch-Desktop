## 一、用户报告问题与根因

### 问题 1: 未打开项目仍显示以前项目的项目图谱，且没有返回键

- **根因**: `ProjectGraphView.vue` onMounted 自动 `restorePersisted()`——localStorage 存有上次 projectId 时，即使工作区未打开任何项目，也会从后端恢复旧图谱展示（重启恢复特性）；该状态无横幅提示、无清除入口（只有"历史回看"有返回按钮），用户无从退出。
- **修复**:
  - 视图新增「无项目恢复横幅」（`pg.graph && !ws.hasProject && !pg.historyViewing`）：明示"正在查看上次会话的项目图谱（源码跳转不可用）"+「清除该图谱」（调 `clear()` 同步清 localStorage）+「前往代码视图」。
  - `projectGraph.backToCurrentProject()` 无备份时（进历史前无当前图谱）退出回看清空回空态——此前 early return 导致横幅"返回当前项目图谱"按钮点了没反应。
  - `removeHistory` 移除的正是正在回看的项目快照时，联动 `backToCurrentProject()` 退出回看（与学习侧对称，不再残留横幅指向已删快照）。

### 问题 2: 获取针对性反馈等久了"自动取消"

- **根因（三层叠加）**: 后端 `/feedback` `asyncio.wait_for(..., 120)` 硬超时到点 504；OpenAI SDK 默认静默重试 2 次把坏/慢端点单调用拖到 3×timeout+，必撞 120s；到点**整单丢弃**（已生成的部分结果也不返回）。前端 loading 文案却写"约 1 分钟"。
- **修复（5 分钟口径）**:
  - `regenerate_for_feedback` 改**截止有界收集**：`as_completed` + 270s 截止，全部完成提前返回；到点未完成的记 `generation_failures`（"生成超时"），已完成的照常返回——不再全有或全无。`shutdown(wait=False, cancel_futures=True)` 不阻塞响应。
  - 单调用封顶：feedback 专用 `_feedback_chat_model()` = `get_chat_model(max_retries=1, timeout=90)`（仍读 ContextVar overrides）。
  - 路由硬上限 120→300s（5min 口径对齐项目质量流水线）；前端 `requestFeedback` timeout 300→330s（保持前端>后端，修正过期"150s"注释）；StageQuiz loading 文案改"最长约 5 分钟"。
  - 时间预算链: 前端 330s > 路由 300s > 再生截止 270s > 单调用 90s×重试1。
