# 2026-08-18 — 文件内联预览（图片 / Markdown / HTML / PDF）

**会话目标**（用户体验第一）：二次开发里点开 PNG/PDF/Markdown/HTML 直接从 Monaco 的"乱码文本"升级为**内联预览视图**。DSH-better-sidebar 借鉴项之二（懒加载目录树已在前一轮）。

## 一、改动

| 产出 | 文件 | 说明 |
|:---|:---|:---|
| 类型分发 | `frontend/src/utils/fileKind.js`（新） | 纯函数：`fileKind`(→image/markdown/html/pdf/text) + `isPreviewKind/isPreviewFile` |
| 预览组件 | `frontend/src/ide/FilePreview.vue`（新） | 图片 base64 `<img>`；Markdown `marked+DOMPurify` 安全渲染（禁 iframe/object/script）；HTML `sandbox="allow-same-origin"` iframe srcdoc；PDF base64 data-url iframe；加载/错误占位 |
| 二进制 IPC | `electron/main/ipc/fs.js` + `electron/preload/index.js` | 新增 `fs:readBase64`（图片/PDF base64 读取，预览专用） |
| 接入 Monaco | `frontend/src/ide/MonacoEditor.vue` | 预览类文件渲染 `FilePreview` 而非 Monaco；守卫：预览文件不 init Monaco、activeFile 切换跳过、revealSymbol 对预览文件只打开不跳转 |
| 打开优化 | `frontend/src/stores/workspace.js` | `openFile` 对预览类文件跳过 utf-8 预读（避免大二进制被当文本读） |

## 三、取舍/边界

- Office（.docx/.xlsx/.pptx）与 Mermaid 不在本批（Mermaid 可后续在 markdown 渲染加 mermaid 块；Office 需引入重型解析，暂缓）。
- HTML 用 sandbox iframe 严格隔离；Markdown 用 DOMPurify 白名单 + 显式禁 iframe/object。
- PDF 走 Chromium 内置 `<iframe data:application/pdf>`；超大 PDF 受 IPC 字符串限制，后续可改流式/字节数组。
