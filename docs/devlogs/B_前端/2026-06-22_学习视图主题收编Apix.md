## 二、关键决策

- **Redesign-Preserve, 不推倒重来**: 按设计技能 Section 11 现代化杠杆优先级, 只做 Levers 1-4 (排版/间距/配色/动效微调), 不动信息架构、store API、后端契约、视图 ID。四个视图的业务逻辑 (computed / ECharts / G6 / 搜索筛选 / 答题闭环) 一字未改。
- **ECharts/G6 用 THEME 镜像常量, 不读 CSS 变量**: canvas 渲染层无法解析 `var(--km-*)`, 故在组件顶部定义 `THEME` 对象, hex 值与 `styles/theme.css` 的 `:root` token 一一对应。token 改色时需同步 THEME (注释已标明)。这是 canvas 类库的固有约束, 非 hack。
- **去 emoji-as-icon**: 阶段0 迁移过来的 `📊📖🔍🛠📝📎⚡🎯` 是 AI-web-template tell。技能纪律禁止 emoji 当图标。表头/Tab 标签改纯文字 (难度星 `⭐` 保留, 它是难度等级的语义计数, 非装饰)。
- **Color Consistency Lock**: 全页单一 `--km-*` + `THEME` 镜像, 一个 accent (暖 Indigo `--km-primary`), 不混 Element 默认蓝绿。暗色模式经 `--el-card-bg-color` 覆盖保证 el-card 不再白底。
- **赛题数据契约全保**: 赛题(3)① 可视化报告 (盲区定位/难度匹配/学习路径)、赛题 M5 质量检测 (幻觉率<5%/适配率≥85%/覆盖率≥90%, 优先后端真实 learning_report)、四层图谱交互、学习路径规划 — 功能与数据源全部保留, 只动视觉层。

## 三、赛题功能影响

零影响: 四个视图的 computed / ECharts option / G6 配置 / 搜索筛选 / 答题提交逻辑全部保留。改动仅限 `<style>` 块 + 个别装饰性 emoji 删除 + `masteryColor` hex 值 (返回值结构不变, 只是颜色 hex 换成同语义的 token 镜像)。
