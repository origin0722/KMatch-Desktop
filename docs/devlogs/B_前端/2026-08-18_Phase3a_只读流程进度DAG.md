## 三、设计说明与边界

- 本版为**只读**，且以 Agent 流水（AGENT_DEFS 序）做线性链近似；编辑/**流程定义驱动真实阶段拓扑**（scene 的 review-profile/review-content 等阶段）+ 拓扑提交事务 → **Phase 3b**（G6 可编辑画布，数据底座为 Phase 2 的 workflow_def + fetchWorkflows）。
- FlowDiagram 刻意做成**纯展示组件**（props: stages），后续 Phase 3b 可复用同一组件加编辑能力，或另建编辑器视图。
