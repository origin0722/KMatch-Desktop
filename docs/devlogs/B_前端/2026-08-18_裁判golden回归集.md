# 2026-08-18 — 裁判 golden 回归集（⑥）：护住 M5 指标口径

**会话目标**：把"改 judge 提示词/模型后无法立刻知道判得准不准"的短板，用 **golden 回归集** 焊死——
离线用假模型驱动全量案例校验 harness + 钉判据措辞，配置 key 时还能跑真裁判 live 回归。

## 一、产出

| 产出 | 文件 | 说明 |
|:---|:---|:---|
| Golden 数据集 | `backend/tests/fixtures/judge_goldens.json` | 8 条幻觉 + 4 条难度案例，取材真实 M5 抓到的错误族：编造实现细节(字节宽度/对象头)、复述事实、超出图谱但领域正确(API 公认)、与图谱相悖(字典迭代改大小)、图谱缺失、切片边界答案错、排序结果错、内容与节点无关；难度含"裁判返回非数值→判定失败"健壮性路径 |
| 离线回归 | `backend/tests/test_judge_goldens.py`（12 例） | ① 数据集合法性；② 假裁判驱动 `judge_hallucination`/`judge_adaptation` 逐案例断言 verdict/coverage/matched，验证 harness(事实拼装/JSON 解析/coverage 归一/计数/invalid 兜底)；③ 一次调用多资源计数/rate 同口径；④ **钉裁判判据措辞**（"不等于幻觉/与图谱事实相悖/编造"等——改判据即红） |
| 真模型 live 回归 | `backend/scripts/run_judge_golden.py` | 自包含(以 golden facts 作图谱，无需 Neo4j)；跑全量/按类、`--fail-fast`；任一不符 → 非零退出 |

## 二、测试

## 三、说明

- judge 本可就注入 `judge_llm`（`quality_judge.py` 已有参数）——golden 双通道据此实现：**离线假模型**每次跑全量（CI 必跑、无 key 也防 harness/措辞漂移），**真模型**在有配置时手动/定时跑（防模型/口径漂移）。
- 数据集即"尺子刻度"，UI/文档/未来换模型都可复用。
