# 桌面应用反馈五连修 — AI 助手工具结果回喂 / 答案解析 / 讲义生成入口 / 图谱自适应

日期: 2026-08-23
范围: 前端 (frontend/src)
涉及版本: v1.0.7 之后 (未动版本号)

## 背景

用户实测桌面应用提出 5 条反馈，本次逐条排查并修复：

1. 学情检测做完题后只有孤零零的答案，缺答案解析
2. 知识图谱"放大看不全 / 缩小看不清"
3. 学习资源中无讲义、资源较少（不确定是搜索缺失还是未配置）
4. AI 助手输入"我要做什么"返回"2"
5. AI 助手生成学习路径报错（原因未知）

## 根因与修复

### 4+5 (严重): 只读工具结果未回喂 LLM — `frontend/src/stores/chat.js`

`summarizeToolResults` 此前只为 read_file / write_file / generate_project_graph /
code_review / code_test / error 写了摘要分支；`search_knowledge`、`get_learning_path`、
`get_knowledge_node`、`query_project_graph`、`web_search`、`generate_learning_resources`
六个工具返回 `''` → 被 `filter(Boolean)` **静默丢弃** → 工具结果从未塞回对话历史。

后果链（与截图完全吻合）：
- 模型看不到"20 个路径节点"，下一轮无法作答；
- 同一轮循环里再次调 get_learning_path（截图中多次"完成 路径 20 个节点"）；
- 6 轮工具上限后模型在无信息下胡答"2"这类无意义短答（问题 4）；
- 用户感知为"生成学习路径报错"（问题 5）。

修复：
- 为 6 个只读工具补摘要分支（含节点/路径/实体/搜索结果清单 + 截断上限，防止上下文膨胀）；
- `get_learning_path` 返回值补 `estimated_total_hours`（后端已有，此前被丢弃）；
- 新增 hint 分支：未完成测评 / 未解析项目等降级引导（`{tool, hint}`）此前同样被丢弃，
  且会被"0 个节点"类空数据分支抢先误读；
- 新增 `assistantApiContent`：全工具调用消息剥离 fence 后为空 → 用占位文本
  `（工具调用已执行，结果见后续对话）` 代替空 assistant content，避免部分厂商对
  空消息响应异常；sendMessage / regenMessage 历史序列化统一走该函数。

### 1: 学情检测答案解析 — `frontend/src/components/AssessmentReport.vue`

后端 `POST /api/diagnostics/submit` 与 demo 工作流返回的 `assessment.questions`
**本就含题库 `explanation` 字段**（出题阶段为防泄露才剥离），前端从未展示。

修复：题目明细每题的"你的答案/正确答案"下方新增 **解析** 行（对错题都展示），
样式与正文区分。题库无 explanation 时不渲染空行。

### 3: 学习资源无讲义 — 定位为"未触发 + 配置依赖"，非搜索缺失 — `frontend/src/views/Learning.vue`

事实：
- 讲义/实操/测试由「学情测评 → 获取针对性反馈」（需 LLM）或 AI 助手
  `generate_learning_resources` 生成（`regenerate_for_feedback` 每目标节点产全 3 类）；
- Learning 页本身**没有生成入口**，用户没点"获取针对性反馈"或没配 LLM → 讲义为空；
- 联网资源另需 Tavily Key，未配置时资源自然偏少。

修复：
- Learning 页顶层空态与讲义 tab 空态新增 **"生成学习资源 / 生成分层讲义"** 按钮
  （复用 store.fetchFeedback 链路，需已测评且有反馈策略），失败时展示可读错误；
- 空态补充来源说明（LLM / Tavily 配置依赖），消除"不知是搜索缺失还是未配置"的困惑。

### 2: 知识图谱缩放布局 — `frontend/src/views/KnowledgeGraph.vue`

G6 默认 zoom=1 不自动适配 → 20+ 节点超出画布（放大看不全）；缩小无下限（看不清）。
- Graph 配置新增 `autoFit: { type: 'view', options: { when: 'always', direction: 'both' } }`
  每次 render 自动把全图适应画布；
- `zoomRange: [0.3, 4]` 约束滚轮缩放（0.3 以下标签不可读）；
- 工具栏新增 **＋ / － / 适应画布** 三个缩放按钮（`graph.zoomBy` / `graph.fitView`）。

讨论项（未在本轮实现，留给用户确认）：
- 默认收起底部详情面板让画布拿满全高；
- 节点尺寸 / 标签字号是否再放大（PERSONA 初学 215×70 已较此前增大）；
- 力导向布局下是否默认聚类显示。

## 影响面

- 仅前端改动；后端无需变更（explanation / estimated_total_hours 后端已提供）。

  重复调工具与"2"类空答消除；未完成测评的降级引导也会如实回传。
