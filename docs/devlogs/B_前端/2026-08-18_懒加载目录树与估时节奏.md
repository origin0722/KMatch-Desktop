## 一、懒加载目录树（卡顿根源与修复）

- **根因**：`workspace.refreshTree()` 原用 `fs.listDirectory(null, { deep: true })` ——**全量深遍历整个项目**，大项目打开/外部变动刷新都会卡。
- **修复**：
  - `stores/workspace.js`：`refreshTree` 只取**顶层**；新增懒展开——`expandedDirs/loadingDirs/dirChildren`（响应式）+ `toggleDir(dir)`（首次展开才逐层 `listDirectory`，命中缓存复用、加载中防重复、切换项目清缓存）。
  - `ide/FileTreeBranch.vue`（新，递归节点）：目录箭头 ▸/▾、惰性拉取、`···` 加载占位、空目录占位、files 保留 dirty 点；点击目录展开/收起、点击文件打开。
  - `ide/FileExplorer.vue`：改由顶层 + 分支递归渲染（移除扁平全量）。
- **效果**：打开/刷新只列顶层；点开目录才拉一层 → 大项目交互秒开。
- 测试：`workspace-lazy-store.test.js`（4：顶层非 deep/惰性+缓存+折叠/loading/reset）+ `file-explorer-lazy.test.js`（3：顶层渲染/点击目录递归/空项目）；既有 `workspace-watcher` 回归通过。

## 二、估时节奏语境（5.2h ≠ 吓人）

- 结论：`estimated_total_hours = Σ estimated_minutes/60`，内置节点 20~40 分钟/个是"连续学时"，数字本身合理；**缺"按每周可学时折周"的语境**。
- 修复：`report_builder` 新增 `pacing={total_hours, hours_per_week(默认6), weeks=ceil(hours/week)}`；前端图谱产出显示 `… · 约 N 周节奏（每周 Xh）`（无 pacing 时回退原样，不做坏）。
- 测试：`test_report_pacing.py`（4）+ `useAgentStatus` +1。
