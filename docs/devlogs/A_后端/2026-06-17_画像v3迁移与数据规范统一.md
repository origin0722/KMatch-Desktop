## 二、核心修复：用户画像 Schema 统一（v3）

### 2.1 问题发现

`前置数据准备指南.md` 中定义的画像格式与磁盘上实际的 4 个 JSON 文件使用**完全不同的字段名和结构**：

| 指南字段 | 磁盘字段 | 冲突 |
|:---|:---|:---|
| `user_id` | `profile_id` | 改名 |
| `theoretical_level` | `theory_level` | 改名 |
| `known_node_ids` (string[]) | `known_topics` (object[]) | **类型不同** |
| `weakness_areas` (string[]) | `weak_topics` (object[]) | **类型不同** |

磁盘格式功能更强（`known_topics` 带 mastery 分数和 error_patterns），且 3 个 Agent Prompt 和 LangGraph Demo 已引用磁盘格式。决定以磁盘格式为基础，吸收指南中的优点，统一为 v3。

### 2.2 v3 格式要点

```json
{
  "profile_id": "UP-BEG-001",
  "name": "零基础的小王",
  "theory_level": 1,
  "practical_level": 1,
  "learning_style": "read_write",
  "target_direction": "Python 基础语法入门",
  "preferred_pace": "slow",
  "time_per_week": 6,
  "known_topics": [
    {"node_id": "PY-001", "mastery": 0.90, "last_test_score": 9.0}
  ],
  "weak_topics": [
    {"node_id": "PY-012", "mastery": 0.35, "error_patterns": ["切片负数索引错误"]}
  ],
  "weakness_areas": [
    "对变量和数据类型等基本概念无认知"
  ],
  "demographics": {...},
  "raw_assessment_data": {...},
  "learning_history": [],
  "recommended_path": {...}
}
```

## 三、validate_data.py v3

升级验证脚本，支持两阶段校验：

```
阶段1 — 知识节点: 字段完整性 / id唯一性 / 前置引用 / 循环依赖
阶段2 — 用户画像: 必填字段 / profile_id格式 / theory_level范围 /
                 learning_style取值 / known_topics结构 / mastery范围 /
                 weak_topics结构 / known与weak交叉重复检查
```

用法：
```bash
python backend/scripts/validate_data.py data/knowledge_base/ data/user_profiles/
```

验证结果：✅ 92 知识点 + 4 画像，0 错误。
