# 幻觉治理四机制（借鉴 J-Space Cognition Suite）

> 阶段18 | 2026/08/16 | 后端质量链路

## 背景

调研了 [J-Space-Cognition-Suite-V3.6](https://github.com/Tiger3807861189/J-Space-Cognition-Suite-V3.6)（基于 Anthropic J-space 全局工作区研究的推理时认知控制层），提取四个可落地的幻觉治理机制。它自己承认"套件不会凭空创造底层模型不具备的知识"——KMatch 的图谱 RAG 恰好补上这一层，四个机制全部叠在现有图谱事实上。

**UX 安全原则**：全部改动落在离线质量脚本 + prompt 层 + 判定输出结构，`/submit`、`/feedback`、`/assess/stream` 交互路径耗时零增加；工作流重试改造是"同延迟更聪明"（不加 LLM 调用）。

## 阶段一 ②：判定 → 携带诊断的定向再生（J-Space 元认知控制）

> 原则："不能改变动作的监控信号只是评论，不是控制。"

**改造前**：裁判判幻觉只写报告不触发任何动作；工作流 reviewer 打回后 content_generator 盲重跑（retry_hint 被产出但从未消费）。

**改造后**：
- `_generate_one` / `_build_generation_prompt` 新增 `correction_hint` 参数（`content_generator.py`）——注入"上轮判定修正要求"
- 新模块 `quality_regen.py`：`regenerate_flagged(resources, hallucination_result, kg)` 对判为 hallucinated 的资源原位替换再生（judge reason 作为 hint，adaptation_profile 反映射 level，`safe_llm_call` 包裹，节点缺失/失败保留原资源）
- 工作流定向重试：`_node_body` 读 `state["review_results"]["retry_hint"]`（仅 `content_phase_entered=True` 时，首轮语义安全）——reviewer 的审核诊断首次被消费
- 离线脚本闭环（`run_quality_test.py`）：judge 后 `hallucinated>0` → 再生 → 只对被替换资源重判 → `independent.regen` 记 before/after；`aggregate()` 聚合 before_rate/after_rate；markdown 报告新增"幻觉定向再生闭环"小节；`--no-regen` 可关

## 阶段二 ①：认识状态自声明 unverified_claims（J-Space Dense Track ✓/?/✗）

> 类比、背景铺垫允许存在，但必须浮出水面——未声明比声明更严重（隐性不可控）。

- 生成 prompt JSON schema 新增 `unverified_claims` 数组（图谱事实之外的陈述，每条一句；完全锚定为空）
- `_generate_one` / `_generate_feedback_one`：字段兜底（非 list 强转空）
- `judge_hallucination`：资源带自声明时 prompt 追加"资源自声明待验证补充"块，裁判优先核验
- 脚本 per_run + aggregate 统计 `unverified_claims_total`（审计覆盖证据）

## 阶段三 ③：先锚定后展开（bridge-before-conclusion）

> 防"结论先行合理化"——写得流畅但与节点脱钩的隐性幻觉。

- 生成 prompt system 新增规则：资源首节（讲义第一小节/实操任务目标/测试首个考察点）必须先用 1-3 句复述节点 summary/key_points 已给事实作锚定，随后的展开只能阐释已锚定事实，结论不得先于图谱依据出现
- `data/prompts/04_content_generator_agent.txt` 设计稿同步三机制小节（先锚定后展开 / 认识状态自声明 / 定向再生）

## 阶段四 ④：验证方式 + 覆盖双记录（J-Space checkpoint 的 verifier+coverage）

- `judge_hallucination.txt` 输出 JSON 新增 `coverage: full|partial|none`（资源内容对节点 key_points 的锚定覆盖度，与 verdict 正交）
- `quality_judge.py` verdict 读入 `evidence_node_ids`（此前被忽略，现留档可追溯）+ `coverage`（非法值兜底 none）
- `quality_metrics.py` 新纯函数 `compute_anchor_coverage(verdicts)` → `{full, partial, none, rate_full}`
- 脚本 `independent.anchor_coverage` 聚合；markdown 独立裁判节加"锚定覆盖"行；逐条明细表加覆盖列

## 报告再生成

四机制生效后的 M5 报告需重跑（需 Neo4j + LLM key，约 20-40 分钟）：

```bash
cd backend && python scripts/run_quality_test.py
# 或只重判裁判口径: python scripts/run_quality_test.py --judge-only
```

产出 `data/quality_report.json` + `docs/质量检测报告.md`，新增"幻觉定向再生闭环"小节与锚定覆盖统计。
