## 三、BUG-031 治本设计

无限循环根因：reviewer 用 `bool(resources)` 判模式，空资源回退画像模式，而画像已通过 → 重新进 graph_controller。

治本：state 新增 `content_phase_entered` 布尔标志，content_generator 三个 return 分支（空路径/LLM未配置/正常）均置 True。reviewer 改用此标志判模式：
- 进入过内容阶段 → 内容模式（即使 resources 空）
- 内容模式 + 空 resources → 直接判不通过（无内容可交付），触发打回 content_generator 或超限降级

orchestrator 画像通过分支加 `over_limit` 守卫作止血双保险。
