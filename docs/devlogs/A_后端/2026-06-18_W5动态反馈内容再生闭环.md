## 四、W5 完整三步闭环

```
1. POST /assess (mode=interactive) → session_id + questions
2. POST /submit ({session_id, answers}) → profile + assessment(判分) + feedback.strategy
3. POST /feedback ({session_id, strategy, profile}) → 针对性再生 resources
```

B 端按 strategy 渲染不同 UI：remediate/scaffold 展示讲义，advance 展示挑战题。

---

## 五、关键设计决策

1. **learning_path 用缓存的出题节点**：interactive 模式未跑 graph_controller，assess 时缓存的 `nodes`（出题候选）即当前学习范围，作为再生目标来源合理。
2. **profile 由 B 端传入 feedback**：submit 响应已含 profile，B 端持有；feedback 接口接收 profile 而非重新判分，避免重复 LLM 调用。
3. **无目标节点返回空 resources**：弱项不在路径中、scaffold 无前置等边沿场景返回 `resources=[]`，不报错（已单测）。
4. **复用 content_generator 字段结构**：再生 resources 元素结构与 generated_content.resources 一致（content_type/source_nodes/content），B 端渲染逻辑可复用。
