## 三、关键设计决策

1. **parse_llm_json 按最外层括号解析**：`{` 和 `[` 候选位置按升序排列，从最早位置尝试 `raw_decode`。修复了原实现中 `{` 优先导致数组被内嵌对象"劫持"的 bug。
2. **LLM 审核失败时基础分满分**：未配置 LLM 或 LLM 调用异常时，四维度默认 1.0，靠硬规则问题拉低分数。不再使用 0.5 的保守默认值（不合理的保守在降级时过于严苛）。
3. **node_id 统一在 engine 层做映射**：所有通过 `_node_from_record` 返回的节点自动获得 `node_id` 字段。`get_node`/`semantic_search`/`assemble_learning_path` 等直接操作 dict 的方法也已同步。
