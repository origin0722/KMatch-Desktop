## 二、关键设计决策

1. **审核对象 = 画像本身**：内容审核本职审"生成内容"，但生成 Agent 第4周才做。本周让审核节点审学情检测产出的画像合理性（node_id 存在性、known/weak 交叉、level 与答题 mastery 自洽）。第4周生成 Agent 就位后审核对象可切换，节点逻辑复用。
2. **硬规则 + LLM 结合**：node_id 存在性、交叉重复用 engine 精确判定（避免 LLM 幻觉）；level 自洽、error_patterns 质量交 LLM。
3. **demo/interactive 双模式**：demo 模式 LLM 自动作答跑通闭环，Postman 友好；interactive 留接口待第5周前端联调。
4. **对齐 C 的 prompt**：State/画像输出/审核报告格式严格对齐 C 已写的 3 个 prompt，正向解锁 C 完成学情检测/审核 Prompt 终稿。
