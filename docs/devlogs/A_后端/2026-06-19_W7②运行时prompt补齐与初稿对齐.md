## 一、背景

质量检测指标全达标后, 审查 prompt 现状发现两个问题:

1. **运行时 prompt 与初稿分离维护会漂移** — 运行时 prompt 硬编码在 `.py` 的 `SystemMessage(content=...)`, 初稿在 `data/prompts/*.txt` (代码不读, 纯交付文档)。BUG-043 修主生成路径漏改反馈路径就是漂移的典型后果。
2. **运行时 prompt 部分内容落后于初稿** — 5 级脚手架(赛题启发式导学核心)初稿 04 有完整描述, 运行时 `_build_generation_prompt` 的 practice_guide 只到第 1 级。

用户明确要求: "运行时 prompt 应该补齐并且优化, 要不然和赛题要求对不上"。

---

## 二、运行时 prompt 全景 (审查结论)

哪些 Agent 真正调 LLM、有运行时 prompt:

| Agent | 运行时 prompt 位置 | 是否调 LLM |
|:---|:---|:---:|
| orchestrator | 无 | ❌ 纯流程编排 |
| diagnostics | diagnostics.py 出题/补题/判分/反馈 | ✅ |
| graph_controller | 无 | ❌ 纯 Cypher + 算法 |
| content_generator | _build_generation_prompt + _generate_feedback_one | ✅ |
| reviewer | 画像审核 + 内容审核 | ✅ |
| code_tester | code_tester.py 测试生成 | ✅ |
| code_reviewer | code_reviewer.py 四维度审查 | ✅ |

**orchestrator / graph_controller 不需 prompt**: 代码验证无 `SystemMessage`/`model.invoke`/`llm_configured` 任何调用。前者是 LangGraph 状态流转编排(条件边 + retry 控制), 后者是 Neo4j Cypher 查询 + BFS/混合检索算法。赛题的"消除幻觉/启发式导学/辩论交叉验证"由调 LLM 的 5 个 Agent 承担, 这两个确定性 Agent 无 prompt 可优化。初稿 01/03 已与运行时逻辑对齐(全字段已实现、W6/W7② 算法已补), 仅作交付文档。

## 三、改动

### 1. BUG-044: 反馈路径难度漏修 (BUG-043 同源漏修)
`content_generator._generate_feedback_one` (动态反馈 remediate/scaffold/advance 再生路径):
- prompt 仍含 `"difficulty_level": 1-5` 字段且 `setdefault` — LLM 自填难度漂移在反馈路径复现
- 修复: prompt 去字段 + 注明"由系统统一赋值"; `setdefault` 改强制赋值节点难度, 与主路径 `_generate_one` 一致
- 影响: 适配率指标在动态反馈内容上从失效恢复

### 2. 5 级脚手架补入运行时 (赛题启发式导学核心)
`_build_generation_prompt` 的 practice_guide `type_spec` 原仅第 1 级, 补全完整阶梯:
- 第 1 级 功能描述 + 预期输入输出
- 第 2 级 算法思路提示
- 第 3 级 伪代码框架
- 第 4 级 关键代码片段(含空白)
- 第 5 级 完整参考代码 + 详细注释
- 学习者按需逐级揭示, 首次仅呈现第 1 级 (引导思考而非直接给答案)

### 3. code_reviewer 初稿新建 (交付缺口)
`data/prompts/07_code_reviewer_agent.txt` 新建 — code_reviewer W6 已实现但缺初稿交付文档。补四维度权重(logic 40%/security 30%/quality 20%/domain 10%)、AST 硬规则一票否决、threshold=0.85 抗幻觉刚性要求。

### 4. 6 个初稿与运行时逐项对齐
01 orchestrator(补全 knowledge_graph/generated_content 实际字段)、02 diagnostics(题库驱动 choice/fill)、03 graph_controller(W6+W7② 弱项覆盖补丁)、04 content_generator(高保真约束+难度系统赋值+5 级脚手架)、05 reviewer(BUG-016 双模式)、06 code_tester(W6 已实现标注)。
