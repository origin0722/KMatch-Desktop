# 2026-08-19 · 端用户免 Docker — 嵌入式图存储（v1.0.0）

> 里程碑：安装包端用户不再需要开 Docker。方案见 [轻量化改造方案_免Docker_嵌入式存储.md](../../架构与设计/轻量化改造方案_免Docker_嵌入式存储.md)，决策见 [ADR-0008](../../adr/0008-embedded-graph-store.md)，issue #50–#56。

## 一句话

Neo4j 是端用户开 Docker 的唯一理由，而它只是 1.7MB JSON 的派生缓存——用进程内 `EmbeddedGraphStore` 替换为安装包默认后端（无 Docker/JVM/端口/秒开），保留 Neo4j 为可选 dev/演示后端。**后端 651 测 + 前端 434 测全绿。**

## 背景

- 打包链路已就绪（PyInstaller sidecar 自启），唯一硬门槛 = Neo4j 需 `docker-compose up -d` + 手动导入。
- 审计：沙箱有无 Docker 自动降级；compose 的 `apoc` 从未被调用；`kb_store` 明确 "JSON 为源, Neo4j 派生缓存"；知识库仅 1.7MB。
- 用户诉求：端用户免 Docker + 功能不受影响 + 丝滑不卡 + UI 符合设计师标准。

## 实现

### 新增
- `backend/app/graph/embedded.py` — `EmbeddedGraphStore`：
  - 只读核心：节点/题目/图遍历（`get_*` 一族），返回形状逐字段镜像 Neo4j（`prerequisites` 不注入、`practice_questions` 落 JSON 字符串、`node_id=source_node_id` 注入）。
  - 图遍历：反相邻接 BFS 等价 `[:REQUIRES*1..N]`，逐层记录距离天然等价 Cypher 最短距离聚合。
  - 路径组装：`assemble_learning_path` / `hybrid_retrieve` 逐段复刻，`_WEAK_PATCH_LIMIT=8` / `difficulty_cap` 与 Neo4j 后端单源对齐（保 M5 覆盖率口径）。
  - 可变数据：项目图谱 / 掌握状态 / 风险标注 / KB 同步落 `data/local/`，原子写（临时文件 + `os.replace`）+ per-file 锁（B3 事务语义）。
  - 向量：`data/local/embeddings.json` 载入 + numpy 余弦（无 numpy 纯 Python 兜底）+ 后台 daemon 自动回填 + `semantic_ready` 三态降级。
- `backend/tests/test_engine_embedded.py` — 14 个单测（形状契约/遍历/路径/项目图/状态/向量三态/降级）。

### 修改
- `backend/app/config.py` — `GRAPH_STORE=neo4j|embedded|auto`（默认 neo4j，保测试零漂移；打包态 run_server 翻 embedded）。
- `backend/app/main.py` — `_build_store()` 按模式实例化；health 增 `graph_store` / `semantic_search` 字段。
- `backend/app/graph/engine.py` — 加 `semantic_ready` 属性（Neo4j 后端 = embedding_client 就绪）。
- `backend/app/api/graph.py` — 语义守卫由 `embedding_client` 切到 `semantic_ready`（唯一 1 行契约改动）。
- `backend/run_server.py` — PyInstaller frozen 态 `setdefault('GRAPH_STORE','embedded')`。
- `frontend/src/stores/backendHealth.js` + `frontend/src/ide/StatusBar.vue` — 嵌入式下显示「本地存储」绿点；语义降级显示「纯图模式」琥珀点（温和提示替代报错），Docker 引导弹层自动隐藏。

### 版本
- 1.0.0：根 `package.json` / `frontend/package.json`(+lock) / `backend/app/config.py` `APP_VERSION`。产物安装包名变为 `KMatch·知链-1.0.0-x64.exe`。

## 关键决策（详见 ADR-0008）

1. **dev/测试默认 `neo4j`，打包默认 `embedded`**：大量集成测试 `TestClient(main.app)` 直接跑 lifespan，`auto` 默认会把无 Neo4j 的测试环境切到嵌入式、改变行为 → 为保"现有测试零改动"，默认保持 neo4j，端用户侧由 `run_server.py` frozen 兜底。
2. **诚实 `semantic_ready` 三态**：语义检索仍需云端 embedding 编码 query，故"有缓存向量但无 key"也一样降级纯图（不夸大离线能力）。
3. **嵌入式 `upsert/delete` 自持持久化**：Neo4j 后端会自写库，嵌入式等价落 JSON（`kb_store.save_node/delete_node` 幂等兼容 kb.py 的"先写再同步"双写）。

## 测试

- 后端：`pytest tests` → **651 passed**（含嵌入式 14 个，含 `test_chat_safety`/`test_submit`/`test_routes_llm_overrides` 等全 lifespan 路径，无回归）。
- 前端：`npm test` → **434 passed / 62 files**。
- 沙箱注意点：Windows 本环境跑 pytest 需把 `TMP/TEMP` 指到工作区内（harness 会把 TEMP 重定向到只读沙箱目录），`--basetemp` 同理；`GRAPH_STORE=embedded` 下可完全无 Docker 跑通后端单测（本里程碑本身即验证了该能力）。
