### 🔴 #1 `AssessmentReport.vue` 按知识点汇总永远显示满分

**严重度**：高（演示时会被发现"明明答错了但绿色 5/5"）
**责任方**：B
**工作量**：10 分钟

**位置**：[frontend/src/components/AssessmentReport.vue:113-115](../frontend/src/components/AssessmentReport.vue#L113-L115)

```js
function nodeCorrect(results) {
  return (results || []).filter(Boolean).length  // ❌ 新结构下 results 元素是对象，永远 truthy
}
```

**根因**：B-2 把 `questionGrades` 改成新对象结构 `[{question_index, correct}]`，但**漏改 `nodeCorrect`**。新结构每个元素都是对象（truthy），`filter(Boolean)` 永远不过滤，导致每个 `<el-tag>` 显示 `node_id — N/N 正确` 且永远 `success` 绿色。
**B-6 单测也漏断言**（`assessment-report.test.js` 没测 `nodeCorrect`）。

**修复方案**：
```js
function nodeCorrect(results) {
  return (results || []).filter(g => g && g.correct === true).length
}
```
同时在 `assessment-report.test.js` 增加 `nodeCorrect` / `nodeTagType` 断言。

**本次会话已修复** ✅（详见本报告末尾「本次会话已落地」节）。

**统一方案（推荐方案 A — 扩展 diagnostics 输出）**：

       "current_node": recommended_start,
       "next_nodes": _suggest_next_nodes(nodes, weak_topics),  # 复用图遍历，取 weak 之后的 3-5 个

### 🔴 #4 `_grade` 的 `question_index` 仍是 grades 数组下标，未根除顺序依赖

**严重度**：中（治标未治本，LLM 漏题/乱序时仍会指错题目）
**责任方**：A
**工作量**：~0.5 天

**位置**：[backend/app/agents/diagnostics.py:149-155](../backend/app/agents/diagnostics.py#L149-L155)

```python
for idx, g in enumerate(grades):       # idx 是 grades 数组下标
    correct_by_node.setdefault(nid, []).append({
        "question_index": idx,         # ❌ 仍假设 grades 顺序 == questions 顺序
        ...
    })
```

**根因**：BUG-022 想根除"前端顺序依赖"，但后端写入的 `question_index` 本身就来自 LLM 返回数组的隐式顺序。如果 LLM 漏题/乱序：
- 旧前端：错位（红绿混乱）
- 新前端：用错位的 `question_index` 索引 questions[idx] → **依然错位**，治标未治本

**修复方案**（A 端认领）：

1. **改 prompt**：在 [diagnostics.py:_grade](../backend/app/agents/diagnostics.py) 的 system 消息加上：
   ```
   严格输出 JSON 数组，元素：
   {"question_index": <题目在原 questions 数组中的下标，从 0 开始>,
    "node_id": "PY-xxx",
    "correct": true|false}
   ```
2. **改后端**：
   ```python
   for idx, g in enumerate(grades):
       q_idx = g.get("question_index", idx)  # 优先用 LLM 显式回写值
       if not isinstance(q_idx, int) or q_idx < 0 or q_idx >= len(questions):
           q_idx = idx  # fallback 兜底
       correct_by_node.setdefault(nid, []).append({
           "question_index": q_idx,
           "correct": ok,
       })
   ```
3. **补单测**：`test_diagnostics_unit.py` 增加"LLM 返回乱序 grades 时仍能正确判分"的用例。
