#### A-1 🔴 提取公共 JSON 工具 + 兜底加保护

**文件**: 新建 `backend/app/utils/json_utils.py`，修改 `diagnostics.py` + `reviewer.py`

将两个 `_parse_json` 合并为一个 `parse_llm_json(text: str) -> dict|list`：

```python
# backend/app/utils/json_utils.py
import json

def parse_llm_json(text: str):
    """从 LLM 响应中稳健提取首个完整 JSON 值。失败返回 {}。"""
    text = text.strip()
    if text.startswith("```"):
        parts = text.split("```", 2)
        if len(parts) >= 2:
            text = parts[1]
            if text.startswith("json"):
                text = text[4:]
            text = text.strip()

    for start_char in ("{", "["):
        idx = text.find(start_char)
        if idx != -1:
            try:
                obj, _ = json.JSONDecoder().raw_decode(text[idx:])
                return obj
            except json.JSONDecodeError:
                continue

    # 兜底 + 保护
    try:
        return json.loads(text)
    except json.JSONDecodeError:
        return {}
```

然后 `diagnostics.py` 和 `reviewer.py` 都改为 `from app.utils.json_utils import parse_llm_json`，删除各自的私有实现。

**影响**: 无，纯重构。

#### A-2 🔴 `_llm_review` 异常时保留硬规则结果

**文件**: `backend/app/agents/reviewer.py` — `_llm_review` + `reviewer_node` 中的 `_node`

当前流程：收集 `hard_issues` → 调 `_llm_review` → `_merge_issues`。如果 `_llm_review` 崩了，异常跳到外层 `except`，硬规则结果全丢。

if llm_configured():
    try:
        dims = _llm_review(profile, assessment)
    except Exception:
        logger.warning("LLM 审核失败，降级为仅硬规则评分", exc_info=True)
        dims = {}  # 空 → 下面用默认值

# 如果 LLM 失败或未配置，fallback 到默认 dims

    dims = {
        "factual_accuracy": {"score": 1.0, "issues": []},
        "hallucination": {"score": 1.0, "issues": []},
        "logic_consistency": {"score": 1.0, "issues": []},
        "teaching_appropriateness": {"score": 1.0, "issues": []},

#### A-5 🟡 `node_id` vs `id` 命名规范化

**文件**: `backend/app/graph/engine.py`

在 `_node_from_record` 中将 Neo4j 的 `id` 映射为对外统一的 `node_id`：

```python
def _node_from_record(self, record) -> Optional[dict]:
    node = dict(record)
    node.pop("embedding", None)
    # 统一对外字段名
    if "id" in node:
        node["node_id"] = node.pop("id")
    return node
```

然后全局替换：`diagnostics.py` 中的 `n["id"]` → `n["node_id"]`。

**影响**: `engine.py` 的所有调用方都要改字段名。范围可控（当前只有 `diagnostics.py` 在用这些方法）。

#### B-2 🔴 适配 `per_node` 新结构

**文件**: `frontend/src/components/AssessmentReport.vue` — `questionList` computed

待 A-4 完成后，`per_node` 结构变为 `{node_id: [{question_index: 0, correct: true}, ...]}`。

`questionList` 改为直接用 `question_index` 匹配，删掉 `nodeCounters` 顺序依赖：

```javascript
// 改后：构建 question_index → grade 的映射
const questionGrades = computed(() => {
    const map = {}
    const perNode = props.assessment?.per_node ?? {}
    for (const [nid, grades] of Object.entries(perNode)) {
        for (const g of (grades || [])) {
            map[g.question_index] = { node_id: nid, correct: g.correct }
        }
    }
    return map
})

const questionList = computed(() => {
    const questions = props.assessment?.questions ?? []
    const answers = props.assessment?.answers ?? []
    return questions.map((q, idx) => ({
        index: idx,
        raw: q,
        question: q.question,
        type: q.type,
        difficulty: q.difficulty,
        options: q.options,
        answer: answers[idx] ?? '',
        grade: { correct: questionGrades.value[idx]?.correct ?? null },
    }))
})
```
