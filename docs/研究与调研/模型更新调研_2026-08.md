## 三、遗漏的重要厂商（建议新增）

按"国内用户 + 学习平台性价比"排序：

| 厂商 | 建议模型 | 理由 |
|:---|:---|:---|
| **智谱 GLM** | glm-4.6 / glm-4.5 / glm-4.5-air ⚠️ | 国产头部，开源+API 双通道，性价比高，测评/代码强；air 便宜适合评测 |
| **xAI Grok** | grok-4 / grok-4-mini / grok-3-mini ⚠️ | 国际新贵，代码与推理强 |
| **字节豆包 Doubao** | doubao-seed / doubao-1.5-pro ⚠️ | 国产量大便宜，国内访问快 |
| **MiniMax** | minimax-text-01 / minimax-m1 ⚠️ | 国产新秀 |
| **Mistral** | mistral-large / mistral-small / codestral ⚠️ | 欧洲开源系，代码档 codestral 值得加 |
| **OpenRouter（聚合）** | 上面全部模型一个 key 全通 | 一张 key 试遍所有厂商，适合本平台"多模型切换"体验；也省去逐个厂商 key 配置 ⚠️ |

> 智谱/豆包/MiniMax 与 DeepSeek、Moonshot、Qwen 同属"国内直连快"梯队，对国内用户最实用；OpenRouter 是聚合器不算厂商，但对本项目体验价值高。

## 四、推荐默认配置（本平台角度）

本项目默认 `deepseek-v4-pro`（主 LLM，项目技术栈锁定）——**不建议换默认**。
建议的补充方向：

1. **更新过时 ID**（必做）：Claude 全家升代、OpenAI 补 gpt-5 系列、Qwen 补 qwen3、Gemini 补 gemini-3。
2. **加轻档**：`deepseek-v4-flash`（若存在）用于学情评测/批量跑批这类对成本敏感的任务，可显著省 token。
3. **加国内厂商**（高价值）：智谱 GLM、豆包、MiniMax——国内用户直连快，且评测/代码场景性价比优于国际厂商。
4. **加 OpenRouter 聚合**（体验价值）：一个 key 覆盖全部模型，设置页的"模型选择"立刻有几十个选项可试。

## 五、注意事项

- **视觉探测**：新加的 VL 模型（qwen3-vl、glm-4v 等）可走现有 `modelVision` 探测逻辑，无需特判。
- **兼容性**：除 Anthropic 走自有协议外，其余均 OpenAI 兼容，接入成本低（`aiSettings.PROVIDERS` 增行即可）。
- **降级策略**：默认模型保持 v4-pro 不动；更新只动 fallbackModels 列表 + 默认不变，风险小。
- **Ollama 本地档**：模型随用户本机 `ollama pull` 而定，fallback 只是示例，不必追新。
- ⚠️ 所有 `⚠️` 项均需上线核实后落代码（本环境无法联网）。
