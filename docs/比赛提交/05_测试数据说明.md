## 四、数据生成与复现

| 目标 | 命令 |
|:--|:--|
| M5 质量批跑（产出 quality_report） | `cd backend && python scripts/run_quality_test.py`（可 `--profiles beginner web_dev` 指定画像） |
| 独立裁判黄金集（真模型 live） | `python backend/scripts/run_judge_golden.py` |
| 离线向量种子再生 | `python backend/scripts/export_embeddings.py` |
| 抽题可复现 | `prepare_questions(..., seed=<int>)` 显式种子 |
| 全量回归 | 后端 `python -m pytest tests -q`（797+2）/ 前端 `npx vitest run`（569） |

复现说明：`data/quality_report.json` 与 `data/workflow_runs/` 为随仓库固化的示例运行数据，**评审无需联网 LLM 即可核验全部字段**；接通 LLM 重跑因模型抽样随机性数值可能略有差异，但字段结构与语义一致（`run.json` 记录 `workflow_id` 可溯源流程拓扑）。

## 五、数据合规（赛题要求(5)）

- 学习者画像全部为**人工构造的合成数据**（虚构人物，无任何真实自然人身份信息）；"年龄/学历/专业"为抽象教学适配维度；
- 用户数据（API Key/对话/画像）仅存本机、后端不回传；交互日志脱敏组件（`PRIVACY_REDACT_INTERACTION_LOGS`）对 `answers/practical_evidence/联系方式` 等敏感键名打码；
- 知识节点与题库为自研策展内容，不含第三方受版权保护文本。详见《[数据合规与隐私保护说明](../合规与安全/数据合规与隐私保护说明.md)》。
