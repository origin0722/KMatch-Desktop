> **赛题编号**：XH-202630 ｜ **题目**：领域知识个性化生成与多智能体协同决策系统研究

## 介绍

**KMatch·知链**以四层知识图谱为多智能体共享事实底座、LangGraph 协同调度 7 个核心 Agent，面向 Python 垂直领域实现「学情画像构建 → 多智能体协同调度 → 领域知识个性化生成 → 交互反馈 → 动态决策更新」的完整闭环，把大模型从"通用聊天工具"变成"懂专业、精技能、能落地"的个性化教育资源生产引擎。

## 解决什么问题

大模型生成教学资源有三大痼疾：**幻觉**（专业内容失实，教育培训不可接受）、**个性化与专业性难调和**（放开限制迎合学情则失准，严格限制保准则千人一面）、**生产成本高**（垂直领域实操资源靠人工开发耗时耗力）。KMatch·知链用「多智能体协同决策」破解：让不同角色的 Agent 相互博弈与交叉验证——既敢按学情个性化生成，又把事实底线牢牢锁在知识图谱上。

## 核心能力

| 能力 | 说明 |
|:--|:--|
| **多智能体协同调度** | 7 个核心 Agent（主控调度/学情检测/图谱管控/内容生成/内容审核/代码审查/代码测试）+ 2 个辅助 Agent（独立裁判/动态建域），LangGraph 编排「诊断 → 画像审核 → 图谱组装 → 内容生成 → 内容审核」五阶段链，打回-再生博弈闭环，全程事件落盘、前端实时可视化 |
| **学情画像构建** | 理论水平 × VARK 学习风格 × 实操倾向三维画像，采集学历背景/编程经验/每周学时，画像跨次进化（掌握度加权合并 + 版本 diff + 遗忘降级） |
| **个性化资源生成** | 每个薄弱节点生成**分层讲义 / 阶梯式实操指南 / 分阶测试题**三形态资源，难度与措辞随画像自适应（beginner/intermediate/advanced），每段内容标注 `source_nodes` 溯源到图谱节点 |
| **抗幻觉质量闭环** | 生成-审核-打回博弈 + 溯源逐条校验 + **独立裁判（LLM-as-Judge）**双口径质检：幻觉率 **2.4%**（达标线 <5%）、适配率 **94.0%**（≥85%）、覆盖率 **100%**（≥90%），10 组差异化画像 × 83 条资源实测 |
| **动态反馈决策** | 按答题正确率三策略迭代：进阶挑战 / 降维解释 / 补前置脚手架；苏格拉底式导学追问打破静态资源单向输入 |
| **双场景覆盖** | 场景一·无项目技能训练（完整学习闭环）；场景二·有项目二次开发（项目自动解析成代码图谱 + 审查/测试双 Agent + 沙箱执行） |
| **桌面 IDE 交付形态** | Electron + Monaco 编辑器 + AI 助手（多厂商/SSE 流式/13 工具调用循环）+ Git 面板 + 运行历史 + 数据看板；安装包内置后端 sidecar 与嵌入式图存储，**端用户免 Docker、免命令行、免配置文件** |

## 技术栈

Electron 33 + Vue 3 + Element Plus + AntV G6 + Monaco ｜ FastAPI + LangGraph（多智能体编排）｜ 嵌入式图存储（默认）/ Neo4j 5.x（可选）｜ OpenAI 兼容 LLM（DeepSeek V4 Pro，裁判可异源独立配置）｜ 千问 1536 维向量语义检索

## 作品亮点小结

1. **事实底座**：四层知识图谱作为全部 Agent 的共享事实源，生成内容逐段可溯源——"每一段教学知识都能回答从哪来"；
2. **博弈抗幻觉**：不是单模型自审，而是生成/审核/裁判三方分离、可异源配置，幻觉率实测压至 2.4%；
3. **真个性化**：同一知识点对零基础学生和资深开发者生成的是两套措辞与难度完全不同的资源（见测试数据 I/O 示例）；
4. **工程完成度**：单文件安装包开箱即用，1366 项自动化测试 + 26 项手动验收用例，发布前经双路代码审查与深度安全扫描。
