# 系统部署说明（评审版）

> 适用版本：v1.3.4 ｜ 平台：Windows 10/11 x64 ｜ 更新：2026-09-03
> 面向评审的部署路径：**形态① 安装包（推荐，5 分钟可用）** / 形态② 源码运行 / 形态③ 可选 Neo4j。
> 完整版（含环境变量全表/打包流程/故障排查）见《[系统部署说明_v1.3.4](../部署与发布/系统部署说明_v1.3.4.md)》。

## 一、形态① 端用户安装包（推荐）

安装后**无需 Docker、无需 Python、无需命令行**。

1. 获取发行物 `KMatch·知链-1.3.4-x64.exe`（约 130MB，GitHub Release v1.3.4 或随附交付介质）；
2. 双击按向导安装（NSIS，默认装到 `%LOCALAPPDATA%\Programs`）；
3. 启动「KMatch·知链」——Electron 主进程自动拉起内置后端 sidecar（`KMatchBackend.exe`，PyInstaller 打包的 FastAPI + LangGraph，进程内嵌入式图存储），状态栏后端健康点变绿即就绪（首次冷启约 3-8 秒）；
4. **唯一必配项**：设置 → AI 助手，粘贴 OpenAI 兼容 LLM API Key（如 DeepSeek）→ 连通性测试通过即可使用。可选：Agent 学习引擎独立 Key（不配自动回退）、Tavily 联网搜索 Key、语义检索 Embedding Key（不配自动降级名称匹配，界面明示）。

**数据落盘**：知识库只读种子在安装目录；可变数据在 `%USERPROFILE%/kmatch-local/`；API Key 仅存本机（`%APPDATA%/kmatch-desktop/`），后端不上传任何用户数据。

## 二、形态② 源码运行（评审审查代码后本地跑）

```bash
git clone https://github.com/origin0722/KMatch-Desktop.git && cd KMatch-Desktop
cp .env.example .env                  # 填 LLM_API_KEY（必填），其余有默认值

npm install && (cd frontend && npm install)
(cd backend && pip install -r requirements.txt)

npm run dev                           # Electron + Vite HMR，自动拉起后端（嵌入式存储，免 Docker）
```

## 三、运行测试

```bash
cd backend  && python -m pytest tests -q     # 797 passed + 2 skipped（63 文件）
cd frontend && npx vitest run                # 569 passed（72 文件）
```

核心模块（多智能体协同调度 / 领域知识生成准确性）的专项测试命令见《03_单元测试用例说明》第一节。

## 四、形态③ 可选 Neo4j 后端

安装包与开发模式默认嵌入式图存储（免 Docker）。如需多端共享图谱：

```bash
docker-compose up -d        # Neo4j 5.x Community（HTTP 7474 / Bolt 7687）
# 启动前设 GRAPH_STORE=neo4j，连接参数默认 bolt://localhost:7687 / neo4j / kmatch2026
```

首次启动检测空库自动导入 `data/knowledge_base/`（12 文件 292 节点 + 423 题）；嵌入式模式以 JSON 为真相源无需导入。

## 五、部署后验证清单（约 5 分钟）

1. 状态栏后端健康点绿色；设置 → AI 助手连通性测试通过；
2. 学习会话：选目标 → 出题 → 答题 → 提交（分步进度：判分 → 画像 → 路径组装）→ 反馈策略；
3. 数据看板（Dashboard）：三图渲染 + M5 指标，二次进入秒开；
4. 知识图谱：路径渲染、节点详情、搜索（未配 embedding 出现降级提示且名称匹配可用）；
5. 打开 `data/example_projects/simple_crawler`：文件树 / Monaco 编辑器 / 项目图谱自动解析 / 实体跳转；
6. AI 助手：普通问答 + `write_file` 审批门。

## 六、常见问题

| 症状 | 处置 |
|:--|:--|
| 后端点红色 / HTTP 0 | sidecar 未起或端口占用；查 `%APPDATA%/kmatch-desktop/logs` |
| 判分 401 | Key 失效或厂商不匹配；设置页重新粘贴（带换行自动 trim） |
| 搜索提示「语义检索不可用」 | 未配 Embedding 的预期降级，名称匹配仍可用；配置后恢复 |
| Neo4j 模式图谱为空 | 确认 `GRAPH_STORE=neo4j` 且连接参数正确，重启自动导入 |
