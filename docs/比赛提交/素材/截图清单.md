# 演示截图清单（8 张）— 供 PPT 嵌入

> 用途：`项目介绍.pptx` 的界面演示页。**截图文件放入本目录（`素材/截图/`）后重建 PPT 即自动嵌入真图**；未就位时 PPT 渲染统一样式占位框，可直接展示，后续替换不影响版式。
> 提交前如已放齐截图，请重建一次 PPT 让真图进包。

## 通用规格

- 分辨率 **1920×1080**（或应用窗口原比例 16:9/16:10），格式 PNG；
- 亮色主题（默认深青珊瑚皮肤），界面字号调大一档保证缩略后可读；
- 截图前关闭无关标签页；涉及 Key/邮箱的画面打码或避开；
- 文件名严格按下方清单（重建脚本按文件名索引）。
