# 演示视频脚本（约 8 分钟）

> 对应赛题提交要求（1）：「10 分钟以内的系统演示视频，需清晰展示：**从差异化学习者学情画像输入，到多智能体协同调度与交互过程的可视化，再到最终个性化领域知识资源生成的完整闭环**」。
> 本脚本在原 10 分钟版（[提交材料_视频脚本与方案大纲](../交付材料/提交材料_视频脚本与方案大纲.md)）基础上收敛至约 8 分钟：三段闭环完整保留并给足时长，开场/报告/场景二/收尾压缩，旁白只讲稳定能力、不展开边缘功能点。

## 录制规格

- 工具：OBS / 系统录屏；分辨率 **1920×1080**；帧率 30fps；应用设为亮色主题（深青珊瑚皮肤）；
- 应用窗口全屏，界面字号调大确保可读；配音可后期录制；
- 镜头原则：**每个画面停留 ≥3 秒再开始旁白**；旁白宁慢勿抢；
- 素材准备：设置页已配好可用的 LLM Key；清空运行历史使演示干净（可选）。

## 与赛题原文的闭环映射

| 赛题要求的闭环环节 | 本视频对应场景 |
|:--|:--|
| 差异化学习者学情画像输入 | 场景 1（两组画像对比 + 测评作答） |
| 多智能体协同调度与交互过程的可视化 | 场景 2（协同阶段 Agent 状态流转 + 事件流） |
| 最终个性化领域知识资源生成 | 场景 3（三形态资源 + 难度自适应） |

## 场景 0：开场（0:00 - 0:30）

**画面**：标题卡「KMatch·知链 — 知识图谱驱动的多智能体协同个性化学习平台」+ 赛题编号 XH-202630，随后切入应用主界面全景（2-3 秒缓慢切换各视图）。

**旁白**：大模型生成教学资源有三大痛点：幻觉、个性化与专业性难调和、千人一面。KMatch·知链以知识图谱为共享事实底座，7 个核心智能体协同决策，攻克专业内容的高保真个性化生成。下面用 8 分钟演示完整闭环。

## 场景 1：差异化学习者画像输入（0:30 - 2:20）★闭环第一段

**画面 A**（0:30-1:10）：学习会话第 1 阶段「目标」。并排展示两组画像设定（可用文档/表格辅助展示）：零基础大一学生（零编程经验、慢节奏、每周 6 小时） vs 有两年前端经验的开发者（快节奏、每周 12 小时）。说明系统内置 10 组差异化画像，本次以零基础画像为主线演示。

**旁白**：系统面向 Python 学习，覆盖"无项目技能训练"与"有项目二次开发"两类场景。我们准备了两组差异最大的画像：零基础学生和有经验的开发者。画像包含学历背景、编程经验、学习风格、每周可学时长等特征，是后续所有智能体决策的输入锚点。

**画面 B**（1:10-2:20）：第 2 阶段「答题」——选择"Python 基础语法入门"方向，系统出题（理论 + 实操，选择/填空/判断题型各出现一次），以零基础学习者的典型水平作答（部分答错），提交后展示分步进度（判分 → 画像 → 路径组装）。

**旁白**：学情检测智能体基于 292 个知识节点的题库动态出题。作答提交后，三维画像生成——理论水平、学习风格、实操倾向，并精确定位薄弱知识点。这些结构化画像直接驱动后续的图谱组装与内容生成。

## 场景 2：多智能体协同调度与交互可视化（2:20 - 4:40）★闭环第二段

**画面 A**（2:20-3:30）：第 3 阶段「协同」——主控调度智能体编排的五阶段流程逐步流转：学情检测 → 画像审核 → 图谱组装 → 内容生成 → 内容审核。每个 Agent 状态实时变化（运行中/完成），进度文案随 SSE 流式更新（如"正在生成学习内容 3/15"）。

**旁白**：主控调度智能体按 LangGraph 流程编排全链路：图谱管控智能体依据画像从知识图谱抽取节点、拓扑排序组装学习路径；内容生成智能体并为每个薄弱节点生成讲义、实操、测试三种资源；内容审核智能体对照图谱事实逐条校验。每个环节的调度事件实时落盘并在界面可视化。

**画面 B**（3:30-4:40）：展示某条生成资源的溯源标注（`source_nodes` 指向 PY-xxx 节点）；如录制中自然出现"审核打回-修正"过程则展示之，否则口头说明机制 + 展示审核四维报告界面。

**旁白**：每段生成内容都标注了引用的知识图谱节点，实现可溯源的约束生成。审核智能体对内容逐条核对：引用了不存在的节点、或与图谱事实不符即打回，附具体修改意见定向再生——通过生成与审核的多轮博弈保证知识高保真。

## 场景 3：个性化领域知识资源生成（4:40 - 6:20）★闭环第三段

**画面 A**（4:40-5:40）：第 4 阶段「图谱」+ 资源交付区——展示该画像生成的三形态资源各 1 条完整内容：分层讲义（学习目标+知识讲解+常见误区）、阶梯式实操指南（真实任务背景）、分阶测试题（基础+进阶两档）。点击资源段高亮其溯源的图谱节点。

**旁白**：通过审核的资源按三种形态交付：分层讲义讲理论，阶梯实操练动手，分阶测试固巩固。所有内容按画像难度自适应——这一组是零基础版本，措辞从最基本概念讲起。

**画面 B**（5:40-6:20）：对比展示开发者画像（UP-WEB-001）对同一知识点（如"列表"）生成的进阶版资源（难度档 advanced、以项目开发为背景的实操任务），与零基础版并排对比。

**旁白**：同一知识节点，对有经验的开发者生成的是进阶解读和项目化实操任务——同一事实底座、两套完全不同的个性化产出。此外，基于答题正确率，系统会动态决策下一步：低正确率降维重讲，高正确率进阶挑战。

## 场景 4：可视化报告（6:20 - 7:10）

**画面**：数据看板 Dashboard——知识盲区分布（掌握度着色）、资源难度匹配、学习路径规划图，M5 三指标（幻觉率/适配率/覆盖率）展示。

**旁白**：系统生成可视化报告：盲区定位、难度匹配、路径规划，并给出经独立裁判质检的三项质量指标——幻觉率 2.4%、适配率 94%、覆盖率 100%，全部优于赛题达标线。

## 场景 5：场景二·项目二次开发（7:10 - 7:45）

**画面**：切到代码视图——打开示例项目 `simple_crawler`，项目自动解析生成代码图谱（函数/类/调用关系），点击实体跳转到 Monaco 源码行。

**旁白**：第二类场景：已有项目二次开发。代码项目自动解析为代码图谱，代码审查与代码测试智能体协同给出质量反馈，薄弱点沉淀回学习路径。

## 场景 6：收尾（7:45 - 8:00）

**画面**：设置页快速横扫一眼（多厂商配置、Agent 独立 Key），结束卡——作品名 + 赛题编号 + 仓库地址 + "KMatch·知链，让大模型真正懂专业"。

**旁白**：桌面 IDE 一键安装、免 Docker 部署，支持多厂商模型接入。KMatch·知链，让大模型从通用聊天工具，转变为懂专业、精技能、能落地的教育资源生产引擎。
