# 单元测试用例说明 — 核心模块聚焦

> 对应赛题提交要求（2）软件模块：「单元测试用例（针对多智能体协同调度逻辑与领域知识生成准确性等核心模块）」
> 测试基线（2026-09-03 实测，v1.3.4）：后端 **797 passed + 2 skipped**（Pytest，`backend/tests/` 63 文件）/ 前端 **569 passed**（Vitest，`frontend/src/__tests__/` 72 文件），合计 **1366 用例**。
> 全量手动验收用例（M-01~M-26）与自动化回归映射（A-01~A-13）见《[测试用例表_v1.3.4](../质量与验收/测试用例表_v1.3.4.md)》，本文聚焦赛题点名的两大核心模块。

## 一、运行方式

```bash
# 后端全量（约 1 分钟）
cd backend && python -m pytest tests -q          # 797 passed + 2 skipped

# 仅多智能体协同调度模块
cd backend && python -m pytest tests/test_orchestrator.py tests/test_workflow_def.py \
  tests/test_run_store.py tests/test_log_events.py tests/test_routes_llm_overrides.py \
  tests/test_assess_llm_overrides.py tests/test_node_overrides_propagation.py \
  tests/test_state_overrides.py tests/test_direct_call_overrides.py tests/test_agents_ping.py \
  tests/test_domain_bootstrap.py tests/test_assess_sse_api.py \
  tests/test_interactive_stream_api.py tests/test_state.py -q

# 仅领域知识生成准确性模块
cd backend && python -m pytest tests/test_content_generator_unit.py tests/test_reviewer_unit.py \
  tests/test_quality_judge.py tests/test_quality_metrics.py tests/test_judge_goldens.py \
  tests/test_quality_regen.py tests/test_content_regen_cache.py tests/test_graph_controller_unit.py \
  tests/test_engine_questions.py tests/test_engine_learning_path.py tests/test_engine_parity.py \
  tests/test_engine_embedded.py tests/test_kb_store_unit.py tests/test_kb_api.py \
  tests/test_question_bank_audit.py -q

# 前端全量（约 1 分钟）
cd frontend && npx vitest run                     # 569 passed
```

> 测试均为离线可跑：LLM 以假模型/桩替换，不消耗 API 配额；`test_prompt_contract.py` 另将提示词阈值/幻觉条款/文风契约钉入版本控制防漂移。
