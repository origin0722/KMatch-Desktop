## 二、提交打包指引

1. **压缩包命名**（发榜单位规定）：`学校—姓名—作品名称—联系电话`
   —— 例：`XX大学—张三—KMatch知链—138XXXXXXXX`
   > ⚠️ 请替换为你本人的真实信息（本资料包内不预置）。
2. **接收邮箱**：602808600@qq.com（申报联系人：刘文霞）；同附审核通过的参赛报名表扫描件；
3. **体积策略**：安装包 130MB + 视频（建议 ≤500MB）+ 源码 → 总包可能超邮箱限制。推荐：压缩包主体（文档 + 源码 + 测试数据，约几十 MB）直发邮箱，安装包与视频传云盘，邮件中附**云盘链接 + 提取码 + 上传截图（含上传时间）**；
4. **源码形态**：优先给 GitHub 链接（私有仓库需为评审开通只读权限并在邮件中说明账号）；同时可在云盘附源码 zip 作为兜底；
5. 提交前自查：本 README 对照表逐项可寻址、视频 ≤10 分钟且含三段闭环、PPT 截图是否已替换真图。
