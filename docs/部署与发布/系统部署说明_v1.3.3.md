# KMatch·知链 系统部署说明（v1.3.3）

> 适用版本: v1.3.3 | 平台: Windows 10/11 x64 | 更新: 2026-09-03
> 三种部署形态: **① 端用户安装包（推荐, 免 Docker）** / **② 开发模式** / **③ 可选 Neo4j 后端**
> 本文是部署的唯一权威入口; 架构背景见 [架构与设计/轻量化改造方案_免Docker_嵌入式存储.md](../架构与设计/轻量化改造方案_免Docker_嵌入式存储.md)

## 一、形态① 端用户安装包（推荐）

面向最终用户与评委演示。安装后**无需 Docker、无需 Python、无需命令行**。

### 1.1 安装

1. 获取发行物 `KMatch·知链-1.3.3-x64.exe`（GitHub Releases 或随附交付介质）。
2. 双击运行 → 按向导完成安装（NSIS 安装器; 默认装到 `%LOCALAPPDATA%\Programs`）。
3. 启动「KMatch·知链」：
   - Electron 主进程自启内置后端 sidecar（`resources/backend/KMatchBackend.exe`，PyInstaller 打包的 FastAPI，进程内嵌入式图存储 `GRAPH_STORE=embedded`）。
   - 状态栏后端健康点变绿即就绪（首次启动 sidecar 冷启约 3-8 秒）。

### 1.2 首次配置（唯一必配项）

进入应用 → 「设置 → AI 助手」粘贴 LLM API Key（OpenAI 兼容，如 DeepSeek）。可选：
- 「Agent 学习引擎」独立 Key（不配则自动回退 AI 助手 Key）。
- 「Tavily Key」（联网搜索学习资源; 不配则反馈生成跳过联网部分）。

### 1.3 数据落盘位置

| 数据 | 位置 |
|:---|:---|
| 知识库（只读种子） | 安装目录 `resources/backend/data/knowledge_base/` |
| 可变数据（项目图谱/掌握状态/向量缓存） | `%USERPROFILE%/kmatch-local/`（`KMATCH_LOCAL_DIR` 可改） |
| 应用配置（API Key 等, 仅存本机） | Electron userData（`%APPDATA%/kmatch-desktop/`） |

### 1.4 可选 Neo4j 后端

安装包默认嵌入式存储; 如需多端共享图谱可切换：启动前设环境变量 `GRAPH_STORE=neo4j` 并提供 Neo4j 5.x 连接（见第四节）。

## 二、形态② 开发模式

```bash
git clone https://github.com/origin0722/KMatch-Desktop.git && cd KMatch-Desktop
cp .env.example .env                  # 填 LLM_API_KEY (必填); 其余有默认

# 依赖 (国内网络建议先配 npm 镜像)
npm install && (cd frontend && npm install)
(cd backend && pip install -r requirements.txt)

# 启动 (二选一)
npm run dev                           # Electron + Vite HMR (推荐, 自动拉起后端)
# 或: 仅前端浏览器调试 + 自起后端:
#   cd backend && GRAPH_STORE=embedded uvicorn app.main:app --reload --port 8000
#   cd frontend && npm run dev        # http://localhost:5173
```

开发约定: 改前端只走 HMR; **改后端 Python 后**若要出新安装包须重跑第五节的 sidecar 打包。

## 四、可选 Neo4j（GRAPH_STORE=neo4j）

```bash
# 国内网络先配 Docker 镜像源: scripts/setup_docker_mirror.*
docker-compose up -d       # Neo4j 5.x Community, 7474(HTTP)/7687(Bolt)
```

环境变量（`.env`，完整清单见 `.env.example`，约 30 项均有默认值）:

| 变量 | 必填 | 说明 |
|:---|:---|:---|
| `LLM_API_KEY` | 是 | OpenAI 兼容 LLM Key |
| `LLM_BASE_URL` / `LLM_MODEL` | 否 | 默认 DeepSeek 官方端点 / `deepseek-v4-pro` |
| `EMBEDDING_*` | 否 | 千问 embedding; 不配则语义检索降级为名称匹配（界面有提示） |
| `NEO4J_URI` / `NEO4J_USER` / `NEO4J_PASSWORD` | neo4j 模式必填 | 默认 `bolt://localhost:7687` / `neo4j` / `kmatch2026` |
| `GRAPH_STORE` | 否 | `embedded`(默认/frozen) \| `neo4j`(默认/dev) \| `auto` |
| `KMATCH_LOCAL_DIR` | 否 | 嵌入式可变数据目录（安装包默认指向用户目录） |
| `JUDGE_LLM_*` | 否 | 独立裁判 LLM（不配回退主 LLM 并在报告标注 same_source） |
| `TAVILY_API_KEY` | 否 | 联网搜索（前端设置页也可填） |
| `SANDBOX_MODE` | 否 | `auto`(默认) \| `subprocess` \| `docker`（代码测试沙箱） |
| `CONTENT_GEN_CONCURRENCY` / `JUDGE_CONCURRENCY` | 否 | 生成/裁判并发度（默认 5 / 4） |

知识库导入（仅 Neo4j 模式首次）: 后端启动时自动检测空库并导入 `data/knowledge_base/`；嵌入式模式以 JSON 为真相源无需导入。

## 五、从源码构建安装包

```bash
# 1) 后端 sidecar (任何 backend/ Python 改动后必须重跑; 产物 backend-dist/)
cd backend && pyinstaller KMatchBackend.spec --noconfirm \
  --distpath ../backend-dist --workpath ../build/pyinstaller

# 2) 前端 + Electron NSIS 安装包 (产物 release/*.exe)
#    国内网络必须配镜像 (一次性设系统环境变量亦可):
export ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
export ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/
npm run build:win
```

- 首次打包需开 **Windows 开发者模式**（设置→系统→开发者选项），否则 winCodeSign 解压 macOS 符号链接报「客户端没有所需的特权」。
- 产物校验: `release/KMatch·知链-1.3.3-x64.exe`；冒烟基线 = 安装后启动、状态栏后端点变绿、完成一次「目标→答题→反馈」全流程。
- `backend-dist/`、`build/`、`release/` 均已 gitignore，不进仓库。

## 六、验证清单（部署后 5 分钟）

1. 状态栏后端健康点绿色；「设置 → API 设置」连通性测试通过。
2. 学习会话：选目标 → 出题 → 答题 → 提交（应看到分步进度与"停止等待"按钮）→ 反馈策略。
3. 报告页（Dashboard）：补跑进度可见，二次进入秒开（缓存命中）。
4. 知识图谱：路径渲染、节点点击详情、搜索（未配 embedding 时出现降级提示条且名称匹配可用）。
5. 打开任一 Python 项目：文件树/编辑器/项目图谱自动解析/实体跳转。
6. AI 助手：普通问答 + `write_file` 审批门。

## 七、故障排查

| 症状 | 原因与处置 |
|:---|:---|
| 后端点红色 / HTTP 0 | sidecar 未起或端口被占; 查 `%APPDATA%/kmatch-desktop/logs` 或以 `GRAPH_STORE=embedded` 手动拉起 uvicorn 复现 |
| 判分 401 | Key 失效/厂商不匹配; 设置页重新粘贴（粘貼带换行会自动 trim） |
| 判分 504（>90s） | LLM 端点过慢; 重试或设置页开启「判分也使用快模型」实验开关 |
| 搜索提示「语义检索不可用」 | 未配 embedding; 属预期降级, 名称匹配仍可用; 配置 `EMBEDDING_*` 后恢复 |
| 生成内容显示「已取消（用户停止等待）」 | 用户点了停止等待, 属预期; 重新触发即可 |
| Neo4j 模式下图谱为空 | 首次未导入; 确认 `GRAPH_STORE=neo4j` 且连接参数正确后重启后端自动导入 |
